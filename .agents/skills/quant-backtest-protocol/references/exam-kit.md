# exam-kit · 把它当"考题"发出去（多模型/多方案横向评测）

用途：同一道量化题发给多个模型（或多个人/多套方案），在**同一份数据、同一笔成本、
同一个目标函数**下横向比较。EP004 就是这么跑的：四家收到逐字相同的一句话。

---

## 题面模板（按需替换 `<>`）

**锁死（改了直接判负）**
- 标的池：`<N 个标的，列全>`，固定在先，不许按表现增删
- 成本：单边 `<X>%`，`<资金费/印花税/借券费>` 真实计入，不许调低
- 杠杆固定 1x；**必须能做多也能做空**，只做多判负
- 目标函数：由我提供的 `<ValidLoss>` 给定，不许自己写
- 数据边界：只有 TRAIN `<区间>` 和 VALID `<区间>`；此环境内不存在其他数据

**开放（自定）**
- 策略家族、时间周期、进出场逻辑、回撤控制、换手控制、仓位管理
- 搜索轮数：只给上限 `<2000>`，**用多少自己判断**（过度搜索会被 DSR 罚）

**硬性要求（违反即判负）**
0. 长短双向都要能开
1. 无未来函数：t 时刻的决策只能用严格早于 t 的信息，**归一化/排名/z-score 同样受此约束**
2. 成本不许调低
3. 宇宙固定
4. 只交付下面列的文件，不多不少；固定随机种子并记录

**交付物**
```
strategy.py            策略本体
config.json            最终采用的参数 + 种子
design.md              策略家族、信号、周期与换手的选择及理由、实际搜索轮数及理由
self_assessment.md     自评：最可能过拟合/最可能有未来函数的地方在哪、为什么
metrics.json           自报指标（只填 train/valid）
hyperopt_results.json  每一轮的 params + train_score + valid_score
run.md                 复现命令
```

`metrics.json` 每段必须含：`ann_return, sharpe, sortino, calmar, max_drawdown,
win_rate, profit_factor, turnover_per_year, n_trades`，夏普用日频资金曲线口径。

> 目标函数是考题本身，必须对所有参赛者相同。**若答题者认为目标函数不对，
> 要求他在 design.md 里说明并给出他会优化什么——有理有据的反对给分，
> 闷声优化别的东西不给分。**

## 五层验收

| 层 | 内容 | 判定 |
|---|---|---|
| 1 硬门槛 | 能跑通、有成交、双向都用、杠杆未超、脚手架未改、成本未偷改、交付齐 | 缺一即负 |
| 2 表现 | 独立复现的滚动 OOS（统一成本、关缓存） | 只认复现值，自报仅用于比对 |
| 3 稳健 | alpha/beta 归因、DSR/PSR、日收益蒙卡、walk-forward 稳定性 | 见 falsification.md |
| 4 可交易性 | 全量 vs 截断因果检查 + 信息/决策/成交/PnL 时序 | 任一不过即负 |
| 5 工程与判断力 | 代码质量、自评诚实度、**是否盲取 argmax**、搜索轮数的克制 | 主观分，依据要写出来 |

**关键分野往往不在收益，而在第 5 层**：肯不肯放弃自己跑出来的最高分那一组。
EP004 里三家算出 train/valid 相关性极低、主动弃掉 argmax，一家直接取了验证集最高分
（valid 2.25 / train 0.65 的反向落差）——这是最清晰的判断力差异，
而且**它在揭盲前就能看出来**。

## 六维评分（0–10，权重可调）

| 维度 | 权重 | 依据 |
|---|---|---|
| 稳健性 | 0.25 | DSR / 蒙卡 prob(profit) / p 值 / VALID→TEST 落差 |
| 无作弊 | 0.15 | 因果检查、成本与宇宙是否被动过 |
| 表现（风险调整、样本外） | 0.25 | TEST 夏普、回撤、跑赢基准多少 |
| 代码质量 | 0.15 | 主观，依据写明 |
| 解释诚实 / 判断力 | 0.15 | 自评是否指出真问题、是否盲取 argmax |
| 性价比 | 0.05 | token/工时成本 |

评分表必须附**每一分的可复现依据**；主观维度要明确标注为主观。

## 出题时最容易被忽略的两件事

1. **成交时点不是 `shift(1)`。** 所有参赛方案都必须声明信息、决策、成交与 PnL 区间，
   并使用信号产生后真实可成交的价格；否则跨市场 overnight 等收益会被错误归因。
2. **给同一份脚手架**：横截面对齐、walk-forward、成本和时序核对由出题方提供并锁死，
   否则各家的"没作弊"是在不同定义下成立的，没法比较。
   脚手架里要写清哪些是**默认值可改**、哪些是**规则不许动**。
