# falsification · 四层证伪的公式与读法

顺序是有讲究的：**因果 → 归因 → 运气 → 路径 → 置换**。
前一层不过，后面全部没有意义（用了未来数据的曲线，alpha 再高也是假的）。

---

## 层 1 · 因果闸（全量 vs 截断）

对同一时点 t，用全量数据算一次决策、用截断到 t 的数据再算一次，**不一致即未来数据**。

这一步能发现最常见的三种数据依赖泄漏：

1. 全样本 z-score / min-max / 分位归一化（用了未来的均值方差）
2. 横截面排名里混进了未来行（面板对齐没 shift，或 rank 之后才 shift）
3. 用未来行或全量缓存计算当前决策

它**不能**证明成交可行。`shift(1)` 完全可能通过，但策略仍把信号产生前已经发生的
overnight 收益记到自己名下。必须另外检查 `information_time → decision_time → execution_time → pnl_interval`，
并拆开 overnight / open-to-close / close-to-close 归因。

横截面策略必须用 `--mode panel`：单标的模式看不到"全池统计量用了未来"。
框架自带的 lookahead 检查对横截面会**误报**（边界那根 K 线排名天然会变），以本脚本为准。

若被测函数走的是框架的 dataprovider、无法直接截断，退而求其次做**框架级对照**：
用两个不同结束日期跑两次回测，比对重叠期的成交是否一致；差异只出现在短区间最后一天 =
边界效应，可判 PASS，但要在报告里注明用的是替代检验。

## 层 2 · alpha / beta 归因

逐日盯市回归：`R_s − R_f = α + β (R_b − R_f) + ε`

输出读法：

- **年化 α**：策略自己创造的部分。α ≤ 0 → 赚的全是大盘，策略本身在做减法。
- **β / R²**：β≈0 且 R² 低 = 真中性（做空确实起作用了）；β 高 = 本质是带杠杆的择时。
- **β 拖累 vs α 贡献**：`beta_drag = β × Σ R_b`，`α 贡献 = Σ R_s − beta_drag`。
  这是把"亏了多少是被大盘拖的、多少是自己作的"拆开的那一刀。
- 反事实写法（EP004 的经典结论）：
  > 年化 α +7.9%，但净敞口 34% 撞上 −45% 的熊市，被 β 拖走 14 个点 →
  > **若做成真中性，这一年约 +6.5%**（事后归因，反事实推算）。

注意：`strategy_total` / `benchmark_total` 是**日收益的加总**（与日频资金曲线口径一致），
不是复利总收益；跨越极端行情时它和净值涨跌幅会有差距，报告里别混用。

配套要看的还有**多空两侧分别的收益**：熊市里空头那一侧没赚到钱，
比总收益为负更能说明策略哪里坏了。

## 层 3 · Deflated Sharpe（Bailey & López de Prado）

回答：**以你这个搜索规模，纯靠运气能刷到多高的夏普？实际有没有显著超过它。**

```
SR0 = sqrt(V/ppy) · [ (1−γ)·Φ⁻¹(1 − 1/N) + γ·Φ⁻¹(1 − 1/(N·e)) ]      γ = 0.5772
DSR = Φ( (SR_d − SR0) · sqrt(T−1) / sqrt(1 − γ₃·SR_d + (γ₄−1)/4 · SR_d²) )
```

- `N` = 搜索轮数，`V` = 各轮验证得分的方差，`T` = 日收益样本数，γ₃/γ₄ = 偏度/峰度。
- 搜得越多、各轮成绩越散 → SR0 越高 → 你的夏普必须显著更高才算数。
- **DSR ≥ 0.95 显著 / 0.90~0.95 偏弱 / < 0.90 大概率是搜出来的运气。**
- 最狠的一刀长这样：搜 400 轮、验证夏普 1.57，而纯运气基线是 2.55 → DSR 0.094，
  **验证成绩在统计上完全不显著**。所以"多搜几轮把夏普刷上去"是负收益操作。

推论：**搜索轮数是要申报的**。用了 300 轮就写 300 轮，别只报最好那一轮。

真正只有一个事前锁死规格时，DSR 没有跨 trial 方差，不应伪造一个 `n_trials=1` 的 DSR；
使用 PSR 并显式传 `--single-spec`。只要试过其他参数、市场、过滤器或评价口径，就不再是单规格。
此外，单卡 DSR 不会校正“从几十张假设卡中挑最好一张”的活动级选择偏差。

## 层 3′ · 蒙特卡洛分块自助

候选验收对 **OOS 日收益**做 block bootstrap，保留一定序列相关性，重采样 5000 次：

- `prob(profit)`：终值为正的路径占比。候选晋级要求 **≥95%**，等价地希望 P5 终值仍为正；
  10% 只够证明“不是几乎必亏”，远远不是可用策略门槛。
- `P5 / P50 / P95`：把"这策略能赚多少"从一个点变成一个区间，写结论时用区间。
- `--block` 取 5~20 个交易日并做敏感性；逐笔成交会把并发仓位错误地当成独立样本，
  只能作为成交诊断，不能与 OOS 日收益拼成同一晋级裁决。

---

## 层 4 · 随机组合置换

宇宙、持仓数、换手频率全部照抄真策略，**只把选股逻辑换成随机**，跑几百上千次，
得到"闭着眼睛在同一个池子里按同样节奏乱选"的夏普分布。

- 真策略夏普的分位 **< 95% → 因子没有信息**，收益来自宇宙选择和仓位结构。
- 这一层专治"我的策略年化 30%"——如果同期随机选也有 28%，那 30% 不是你的功劳。
- 权重同样要滞后一期（t 日持仓由 t−1 收盘决定），否则置换基线本身带未来函数，
  会把门槛抬得虚高。

---

## 层外 · p 值

`H0: 日均收益 = 0` 的分块自助检验。用来区分"真的在赚/亏"和"被少数几天带出来的噪音"。
样本外**显著亏损**（p < 0.05 且均值为负）是最坏的一档——不是运气不好，是策略方向反了。

---

## 汇总裁决

`qbt.py report` 会把上面全部跑完并给出 `falsification_failures`。
任意一条命中就不能下"策略可用"的结论。**通过全部四层也只是"可以进入小仓位实盘观察"**，
不是"可以上仓位"——回测与实盘之间还隔着滑点、冲击成本、可得性和执行延迟。
