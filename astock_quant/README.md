# astock_quant —— A 股多因子横截面选股研究

一套从数据下载到回测、从因子检验到自动化防未来函数测试的完整框架。
与 Next.js 站点无关，属于本地研究产物，**不入 git**（仅本 README 留档）。

## 结论速览（2026-09 全市场，滚动样本外 2019-01 ~ 2026-09）

按 `quant-backtest-protocol` 的格式写：

> **样本外 2019-01~2026-09（沪深300 +5.75%/年）：策略年化 12.68%、夏普 0.59、
> 最大回撤 −38.0%；对可投池等权基准超额 +4.29%/年，β_沪深300 0.84、β_小盘风格 0.82，
> 净收益口径年化 alpha +5.09%（NW t=1.75，p=0.080），毛口径 +7.48%（t=2.60，p=0.009）。
> 随机组合置换 200 次全部跑输（分位 100%，p=0.005，换手匹配 14.4× vs 17.2×）；
> 蒙特卡洛超额为正路径 81.2%；Deflated Sharpe 0.743（不显著）。
> 剔除 2024 年后 alpha 降至 3.79%、t=1.26，八年里超额为正的只有 4 年。**
> **结论：因子确有信息（置换与因果两关都过），但净收益 alpha 未达显著、
> DSR 未过 0.90、收益集中于单一年份 —— 不具备上仓位条件。**

参数是**只用样本内**选出的（300 只 / 20 日 / 缓冲 3），没有用样本外信息。

## 三个可直接复用的结论

1. **A 股中期动量是负的**。60 日动量 IS ICIR −0.03 / OOS −0.20，120 日 OOS −0.20，
   52 周新高 OOS −0.24（t=−2.0）。美股那套动量在 A 股方向相反，样本内外一致。
2. **因子信息几乎全在空头端**。ivol60 的 OOS 分层年化是
   Q1 −6.5% │ Q2 +2.9% │ Q3 +7.9% │ Q4 +12.3% │ Q5 +12.7% —— Q2~Q5 近乎持平。
   价值在「避开最差的 20~40%」，不在「精选前 20%」。多空年化 24% 拿不到：A 股个股不能做空。
3. **成本决定成败，且门槛可以直接算**。双边约 0.35%（佣金万 2.5 + 印花税千 0.5 +
   滑点 10bp×2）。年化换手 20 倍 = 每年白交 3.5%。**周频以上调仓的量价策略，
   毛 alpha 不到 4% 就别做**。初版毛 3.79%，正好卡在门槛下面，净 alpha 归零。

## 两个自己踩出来的坑（都靠"数字太好看"发现的）

- **分层权重 ffill 滚到 6.16 倍**：调仓日权重直接 `ffill`，上期选中、本期落选的股票把
  旧权重一路带下去。表现是所有分层年化都在 −60%~−80%。修在 `quicktest.daily_weights`，
  测试 `test_daily_weights_sum_to_one`。
- **最小成交额阈值把宽组合变成"拿着不动"**：引擎跳过小于总资产 0.05% 的委托；持仓
  2700 只时单只仅 0.037%，买卖全被静默跳过，换手率失真成 2.3 倍、业绩虚高 5 个点。
  注意这个阈值是**相对**总资产的，加资金没用。引擎现在返回 `blocked_frac`，超过 5%

## 为什么这么设计（踩坑记录）

- **数据源**：东方财富接口在本机网络返回空包，网易 chddata 常年 502，新浪只有当前快照
  列表。腾讯 `fqkline` 稳定，且**保留已退市股票的历史**（sh600005 武钢股份数据止于
  2017-01-23）—— 这是构造无幸存者偏差股票池的前提。单域名高频请求会被限流（HTTP 501），
  用 `ifzq.gtimg.cn` / `proxy.finance.qq.com` / `web.ifzq.gtimg.cn` 三个域名轮换 + 指数退避。
  单次请求上限 800 根，历史靠把 end 往前挪分段拼接。
- **后复权而非前复权**：前复权价会在未来分红送转发生时被改写 —— 用它回测等于让历史价格
  知道未来的分红。
- **股票池穷举代码空间**：用"当前上市列表"会天然剔除所有退市公司。改为扫描
  600000-603999 / 605xxx / 688xxx / 000001-003999 / 300xxx-302xxx 全部代码空间。
- **脏数据**：连续交易日出现 |涨跌幅| > 25% 的记录（A 股有涨跌停，不可能）几乎都是复权
  因子出错或退市整理期的脏数据，一根就能把等权组合净值打穿。检测到即从该日起截断该股。
- **IC 的 t 统计量**：20 日前瞻收益的日频 IC 序列高度自相关，直接用全样本算 t 会把显著性
  放大好几倍。改用非重叠子样本。
- **换手缓冲**：A 股双边成本约 0.3%，无缓冲的周频调仓年化换手 50 倍、成本拖累 8%+，
  再好的因子也被吃光。已持有的股票只要还在前 top_n × 2 名就不换。

## 有没有真 alpha：四层统计检验

思路参考 [frank-quant/ai-trading-videos EP004](https://github.com/frank-quant/ai-trading-videos/tree/main/EP004_four-llm-quant-benchmark)
的三层验证，按 A 股横截面选股的特点做了适配。绝对收益高不等于有 alpha ——
敞口大一点、风格偏一点，牛市里都能跑赢指数。

1. **alpha / beta 归因**：日收益对沪深300 + 小盘风格（等权全A − 沪深300）回归，
   截距即 alpha，t 值用 Newey-West 修正（日频收益有自相关，不修正 t 值会偏大）。
   剥掉「买小票」这个人人都能做的暴露之后还剩多少，才是选股本事。
2. **Deflated Sharpe（Bailey & López de Prado）**：以本项目实际试过的参数组合数量，
   纯靠运气能刷到多高的夏普。DSR < 0.95 视为不显著。
3. **分块自助法蒙特卡洛**：block=10 保留序列相关性，重采样 5000 条路径，
   给出绝对收益与超额收益的 prob(profit)。
4. **随机组合置换检验**：同一个股票池、同样的持股数与调仓日、同样的换手缓冲，
   把打分换成随机数跑 N 次。这是选股策略最直接的证据 —— 它把市场、股票池、
   调仓节奏全部控住了。为避免换手差异干扰，两边都按零成本口径比较
   （随机组合的换手实际比策略还高一点）。p 值用 (1 + #{随机 ≥ 实际}) / (N + 1)，
   最小只能到 1/(N+1)，不会出现「p = 0」这种话。

## 防未来函数：怎么验的

不靠"我检查过了"，靠 `tests/` 里可重复运行的机器验证：

1. **截断不变性**：把数据在某日截断后重跑，截断日之前的因子值与净值必须逐点相同。
   真实交易在那天本来就只有这些数据，结果一旦变化即证明用到了未来。
2. **未来扰动不变性**：把截断日之后的数据换成随机数，历史结果同样必须不变
   （能抓住"全样本标准化"这类隐蔽泄漏）。
3. **反向验证**：故意造一个偷看次日收益的因子，检验必须报警 —— 否则说明检验本身太松。
4. **AST 静态检查**：因子/股票池/策略模块里不允许出现负向 `shift` 与 `bfill`。
5. **引擎已知答案测试**：成本、印花税税率切换、涨跌停、一字板、停牌、退市清算、T+1、
   现金约束，逐条用构造性例子精确核对。
