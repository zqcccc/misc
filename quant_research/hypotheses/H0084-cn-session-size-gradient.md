# H0084 · A股「隔夜亏、日内赚」是小盘口径而不是全市场结构：在个股面板（2015-2026，用原始价+显式除权还原，不用B0005所指的加法复权hfq）上按自由流通市值十分位分解隔夜/日内段，预测日内段年化随市值分位单调下降、隔夜段随市值分位单调上升（秩相关|rho|>=0.7），且市值加权全A的隔夜段年化绝对值不足等权口径的一半；据此对中金所股指期货做出事前预测——把H0043已算过的池子日内段（-6.99%/年）按合约拆开后，IC/IM（中小盘）的日内段应显著高于IF/IH（大盘）。主判读线（可交易）：IM日内段（开盘价买入、收盘价卖出、隔夜空仓）在锁死单边1.0bp下2022-2026净年化>0且NW t>=2、成本压力档x2后仍>0、对'一直持有IM主力'的静态对照增量截距NW t>=2、最大回撤<=25%；所有分段结论按B0018同时报MDE，MDE>效应量时只写'测不出来'

## 1. 假设（一句话，可证伪）
> **A 股「隔夜段亏、日内段赚」的强度随市值单调递减——它主要是小盘口径的产物，不是全市场结构。**
> 由此给出两个事前预测：
> **P1（结构）** 在个股面板上按自由流通市值十分位分解，**日内段年化随市值分位单调下降、隔夜段年化随市值分位单调上升**
> （Spearman 秩相关 |rho| >= 0.7），且**市值加权全A的隔夜段年化绝对值不到等权口径的一半**。
> **P2（可交易）** 把 H0043 已算过的股指期货池子日内段（-6.99%/年）**按合约拆开**后，
> **IC/IM（中小盘）显著高于 IF/IH（大盘）**，且 **IM 日内段本身净年化>0 且 NW t>=2**。

**证伪条件**：市值加权全A的隔夜段年化仍显著为负、且量级不小于等权口径的一半 -> 假设错，
「隔夜亏日内赚」是全市场结构，H0028 与 H0042/H0043 的矛盾另有解释。

## 2. 机理（为什么应该成立）
**T+1 是一条只约束现货、不约束期货的制度，而它对小盘股的约束最紧。**

- **谁被迫付钱**：T+1 下当天买入不能当天卖出，**持有隔夜等于免费送出一个当日的看跌保护**
  （买入后若当晚出坏消息，第二天才能跑）。愿意承接这个风险的人要求补偿 -> **隔夜段应当折价**。
  这笔"期权费"的大小正比于**标的的隔夜跳空风险**，而跳空风险与市值强负相关。
- **为什么随市值递减**：① 大盘股有股指期货、ETF、融券等对冲工具，隔夜风险可被转移，折价被套走；
  ② 小盘股的边际买方是散户，集合竞价情绪买盘集中在开盘，机构无法用日内对冲中和；
  ③ 小盘股的隔夜跳空方差大得多，同样的风险厌恶下要求的折价更大。
- **为什么期货是反的**：**股指期货 T+0**，隔夜风险随时可平，T+1 折价这个机制在期货上根本不存在；
  期货隔夜段为正（H0043 +5.07%/年）另有来源——**深贴水的基差收敛按钟点分摊**，
  而隔夜段占日历时间的四分之三。
- **本卡的主判读腿为什么免疫 H0057 的坑**：按前一日持仓量选主力后，**日内段（开盘->收盘）永远发生在同一张合约内**，
  换月跳变只可能污染隔夜段，污染不到日内段。

## 3. 先验检索（动手前必做，写结论不写过程）
- **正面（三条）**：
  ① Lou-Polk-Skouras《A Tug of War》：美股隔夜/日内是两个不同的期望收益源，且**大盘股的隔夜分量更强**
     （小盘 overnight 三因子 alpha 0.54% vs intraday 0.39%）——**方向与本卡预测同构**。
  ② 《财经研究》2020（T+1 隔夜折价与月频动量消失）：A 股同时存在日内动量与隔夜动量、两者间强交叉反转；
     并明确记录**日内赢家市值较小、隔夜赢家市值较大**——**这正是本卡 P1 的独立佐证，且来自另一套数据**。
  ③ 券商侧（中信建投 2025-11「隔夜-日内异象因子」专题）说明这条线在国内已被当作因子在做，
     **意味着拥挤风险真实存在**，不能假设它还没被交易。
- **负面 / 方法学警告（找到了三条，全部转成本卡的稳健性检验）**：
  ① **LPS 自己承认微观结构嫌疑**，处理办法是：剔除 microcap、并用**开盘半小时 VWAP 与买卖中价**两种口径重算开盘价。
     我拿不到分钟数据与报价中价 -> **本卡必须承认这一条无法照做**，改用「剔除涨跌停日」「缩尾」两个替代检验，
     并在结论里写明这个替代不等价。
  ② 中文实证普遍**对收益做 1%/99% 缩尾**，理由明写是「避免涨跌停和小盘股脉冲主导结果」——
     说明**不缩尾的量级本身就不可全信**。§5 因此把「缩尾版 / 剔涨跌停版 / 原样版」三个都写成必报项。
  ③ **一字涨跌停会把当天全部收益记进隔夜段**（open=close=涨跌停价 -> 日内段恒为 0），
     停牌复牌的缺口同理。小盘股这两件事都远多于大盘股，**这本身就是一条"假象"路径**，
     而它与本卡的假设**同向**——所以本卡不能只报主口径就宣布假设成立，必须报剔除后的版本。
- **与台账相邻但不重复**：
  - **H0028（本卡 parent）**：量出全A等权隔夜 -21.7%/日内 +28.6%，但**没有做任何市值分层**，
    也没有和期货对账；且它用的是 `data/panel/{open,close}`（B0005 已证为**加法复权**，收益被系统性压缩）。
  - **H0043 §7 行 D**：池子日内段 -6.99%/年（t=-1.00），**四品种合到一起**，没有按合约拆。
  - **H0069**：曾为回答同一个矛盾占坑，因主口径与 H0043 行 D 重复而**释放，矛盾没被回答**（见其探索日志）。
  - 本卡与它们的区别：**新的切分维度（市值）+ 新的价格口径（原始价，绕开 B0005）+ 按合约拆的期货腿**。

## 5. 口径锁死（写完不许再改）
- **策略角色**：`alpha`（可交易腿为期货日内段）；个股面板部分是**结构诊断，不下单**。
- **样本**：个股 2015-01-05~2026-09-02；期货 IM 2022-07-22~2026-09-04（IM 上市日起），
  附报 IF/IH（2010+/2015+）与 IC（2015+）同口径。
- **分段定义（锁死）**：
  `日内_t = close_raw_t / open_raw_t - 1`；
  `隔夜_t = open_raw_t / preclose_adj_t - 1`，其中
  `preclose_adj_t = (close_raw_{t-1} - cash_per_share_pre_split_t) / share_multiple_t`（无除权事件时即 `close_raw_{t-1}`）；
  `全天_t = (1+隔夜_t)(1+日内_t) - 1`。**全部用原始价，不用任何复权序列。**
- **可投池（PIT，只用 <= t 的信息）**：`tradestatus=1`、`volume>0`、上市满 60 个交易日；含已退市股。
- **市值口径**：自由流通市值 `= close_raw_t x volume_t/(turn_t/100)`，`turn` 缺失时用**最近一个有效值前向填充**
  （只向前填，禁止 bfill）；十分位在**每个 t 的可投池内**做截面排名。
- **脏数据（锁死）**：`|隔夜| > 0.11` 或 `|日内| > 0.21` 的股-日置 NaN（超出涨跌幅上限一定是未还原的除权或错价）。
- **三个必报版本**（只报不改主判读）：**V0 原样** / **V1 剔除当日触及涨跌停的股-日** / **V2 截面 1%-99% 缩尾**。
- **成本**：股指期货**单边 1.0bp**（沿用 H0042/H0043/H0047 的锁死值），日内段每日一进一出 = 2.0bp/日。
  个股面板部分不下单、不计成本。
- **A 层硬闸**：期货腿在跑 T1~T4 之前**先跑 `qbt.py screen`**（毛年化取实测、换手 488 单边/年、1.0bp）；
  `STOP` 直接 FAIL，不做后续。
- **判读线（事前锁死）**：
  - **结构线（P1）**：
    `S1` 等权全A：隔夜段年化<0 且 日内段年化>0（复现 H0028 的**符号**；量级允许不同，因为口径不同）。
    `S2` 十分位：日内段年化 vs 市值分位 Spearman rho <= **-0.7**，且 隔夜段年化 vs 市值分位 rho >= **+0.7**。
    `S3` 自由流通市值加权全A的**隔夜段年化绝对值 < 等权口径绝对值的 50%**。
    **S2 或 S3 任一不过 -> 假设证伪**（是全市场结构，不是小盘口径）。
  - **可交易线（P2，IM 日内段）**：
    `T1`（主）净年化>0 且 NW t>=2（lag=5）；`T2` 成本x2 后 T1 仍成立；
    `T3` 对「一直持有 IM 主力（全天暴露）」静态对照的增量回归截距年化>0 且 NW t>=2；
    `T4` 最大回撤 <= 25%（期初本金计入净值路径，协议 v7 口径）。
    **T1 不过即 FAIL**，T3 是防止「这只是又一次买了全天暴露」。
  - **`B0018` 要求**：所有分段/子样本同时报 MDE(80% 功效，`2.80xSE`)；
    **MDE > 效应量时只许写「测不出来」，不许写「某段失效」。**
- **成交时序**：`information_time` = t 日开盘价成交那一刻（无预测信号，是无条件持有一段）->
  `decision_time` = 无（无条件）-> `execution_time` = t 日开盘 / t 日收盘 ->
  `pnl` = t 日开盘 -> t 日收盘。**日内段永远在同一张合约内，换月跳变污染不到它（H0057 的坑在此不适用）。**
- **trials 预先登记 = 6**：个股 3 个版本（V0/V1/V2）x 1 个构造；期货 4 条腿（IM 主、IF/IH/IC 附报）
  归为 1 个构造 + 静态对照 1 + 成本压力档 1。**无参数搜索**（分位数固定十分位、成本固定、样本固定）。

**FAIL —— 成本吃穿。**

主判读腿（IM 日内段）在 A 层成本闸就 `STOP`（毛/成本 0.455，压力档 0.227），四条可交易线全不过。

**这是全市场结构，不是小盘口径。**

**必须记下的三条诚实说明**：
① **我原来的假设错了，而且是被我自己的十分位表推翻的**：梯度真实存在且单调（日内 D1 +48% → D10 +23%，
   ρ=−0.99），但它**只把效应削掉四成，没有削到零**。「有梯度」≠「是小盘造成的」——这两句话我事前混为一谈了。
② **本卡最大的技术教训是我自己写的一个未来函数**：用当日收盘市值做权重，让市值加权全A 的全天年化
   从 4.52% 虚增到 18.18%（复利 1.26× → 5.68×）。它不会报错、不会看起来荒谬，
   只会让"大盘也很赚"这个结论凭空成立。**是靠"这个数和沪深300 对不上"才抓出来的。**
③ **可交易性上本卡没有新增量**：H0043 已经判过池子日内段，本卡只是把它按品种拆开并加了指数对账；
   拆开后方向符合预期但**统计功效完全不够**（MDE 是效应量的 3~8 倍），不能当成"IC/IM 更好"的证据。

## 9. 留给后人的一句话

**A股「白天涨、晚上跌」是全市场结构，连上证50 都成立（日内 +14.6%/年、隔夜 −13.3%/年，都显著）——
但你在股指期货上拿不到它，因为贴水正好是"日内压深、隔夜补回"，节律更大、符号相反，把它整个盖住了。**

**四条可复用的结论**：
1. **台账里 H0028（现货隔夜亏日内赚）和 H0042/H0043（期货隔夜赚日内亏）不矛盾**，
   两边的账能对到 0.0000 pp：`期货段 = 指数段 + 基差段`。沪深300 每天日内基差走阔 8.9bp、
   隔夜收窄 10.2bp，净 +1.3bp/日 —— **这 1.3bp 就是 H0043/H0047「一直持有期货每年多赚八个点」的全部来源**，
   而且它**只能靠一直持有拿到**，任何按段切分都会在其中一段做反向。这也再次解释了 H0050/H0055 为什么"切换必输"。
2. **别用当日收盘市值做权重或做分位。** 这是一个不报错、不荒谬、纯记账的未来函数：
   涨了的股票自动获得更大权重，本卡实测让市值加权全A 的全天年化虚增 **13.7 个百分点**
   （4.52% → 18.18%，复利 1.26× → 5.68×）。**抓它的唯一办法是拿一个真实指数去对账**——
   任何自建的"市值加权全市场组合"，都应该先和沪深300/中证全指对一次累计涨幅再往下用。
3. **A股日内段有一半来自触及涨跌停的股-日**（等权全A 日内 +34.7% → 剔除触板日后 +17.7%），
   而隔夜段完全不靠它（−26.4% → −29.3%，反而更负）。做任何日内段研究之前先把这两个数摆出来。
4. **`astock_quant/data/panel/{open_raw,close_raw}` + `data/corporate_actions.csv` 手工还原的全天收益，
   与 baostock 官方 `pctChg` 在 1 038.9 万个股-日上中位差 1.7e-7、除权日无一超过 1e-2** ——
   这条管线可以直接复用，**不需要碰 B0005 所指的加法复权 hfq 面板**。脚本见 `cn_index_futures/h0084/verify_decomp.py`。
