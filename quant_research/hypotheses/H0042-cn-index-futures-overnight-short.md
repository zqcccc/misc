# H0042 · 在中金所股指期货（IF/IH/IC/IM，逐日按持仓量选主力合约）上做空隔夜段——每交易日收盘价开空、次日开盘价平仓、日内空仓——在锁死单边1.0bp成本与合约真实基差下，2010-2026日频资金曲线净年化>0且NW t>=2，且2019-2026后半段单独为正、随机时移置换分位>=95%、最大回撤<=20%

## 1. 假设（一句话，可证伪）

> 在**中金所四个股指期货品种（IF 沪深300 / IH 上证50 / IC 中证500 / IM 中证1000）**上，
> 每交易日**收盘价开空当日主力合约、次日开盘价平仓**（日内空仓、隔夜持有空头），
> 等权 4 个品种、锁死单边 1.0bp 成本，2010-04-16~2026-09 的日频资金曲线
> **净年化 > 0 且 NW t ≥ 2**。

推翻它的四种方式，任一成立即证伪：
① 载体（期货合约价格）本身的隔夜收益不为负 → 做空这一段没有毛边际；
② 净年化 ≤ 0 或 NW t < 2；
③ 2019-2026 后半段单独为负（说明只是早年放开前的残留）；
④ 随机时移置换分位 < 95%，或最大回撤 > 20%。

## 2. 机理（为什么应该成立）—— 以及它最可能错在哪

**制度约束（继承 H0028 已经量出来的指纹）**：A 股 T+1 把一个交易日切成两段。
当日买入不能当日卖出，隔夜段的价格只能由「愿意扛一整夜无法退出风险」的资金决定，
于是开盘价被系统性压低。H0028 在**个股等权**上量到隔夜段年化 −21.7%、日内段 +28.6%，
本卡开工前在**四个宽基指数**上复量，结论一致且非常稳（见 §7 A 层）。

**为什么以前拿不到这笔钱、本卡凭什么认为现在能拿到**：
H0028 §9 的原话是「信息在空头端，而 A 股个股不能做空 → 这一格拿不到钱」。
但它**没有考虑股指期货**——中金所股指期货是 A 股体系里唯一能做空隔夜、
且**不触发平今仓惩罚性手续费**的载体（收盘开仓、次日开盘平仓属于「平昨」，
手续费万分之 0.23，而平今是万分之 3.45，差 15 倍）。这就是本卡要验的那个缺口。

**事前写死的最大怀疑点（对应打分卡「付钱者与持续性」只给 1 分）**：
股指期货是 **T+0**，套利者可以在任意时点进出。如果他们知道明早指数要低开，
**会在收盘前就把期货价格压到贴水更深的位置**——那么这笔隔夜折价就已经被定进
**收盘基差**里，期货自身的隔夜收益会是 0 甚至为正，做空它一分钱也拿不到。
**这不是补救性的辩解，是占坑时就写在卡上的证伪路径 ①。**

## 3. 先验检索（动手前必做）

**找到了明确的负面证据，而且直接打在本卡的证伪路径 ① 上：**

- **Economic Modelling, "T+1 trading mechanism causes negative overnight return"**：
  中国股市隔夜收益显著为负，而**处在 T+0 机制下的品种——包括中国股指期货、港股、主要国际指数
  ——隔夜收益都在 0 附近或为正**。平均 T+1 折价约 14bp。
- **Journal of Empirical Finance, "The overnight return puzzle and the T+1 trading rule in Chinese stock markets"**：
  同一结论，T+1 禁止当日回转导致开盘价折价。
- Int. Rev. Fin. Anal., "Day-night anomaly returns in China: The role of institutions"；
  Economic Modelling, "Positive feedback trading, the T+1 rule, and asymmetric return reversals in China"：
  均把这个异象定位在**受 T+1 约束的现货**上，不是期货。
- 没有找到任何一篇说「做空中国股指期货隔夜段能赚钱」的文献或实盘帖 —— **吹的一篇都没有**。

**与台账的关系**：`--parent H0028`。H0028 是**横截面选股**（用过去 20 日累计隔夜收益排序选个股），
本卡是**时序择时**（直接交易隔夜这一段），市场 id、载体、数据源全部不同，不算重复探索。
H0013（商品期货隔夜/日内 tug-of-war）死在连续合约拼接污染；**本卡结构上不会踩到那个坑**：
每一晚的盈亏都在**同一张合约内**计算（t 日收盘开的仓，t+1 开盘平掉的是同一张），换月不产生跨合约收益。

## 4. 数据需求

- **一手源：中金所官方历史行情** `http://www.cffex.com.cn/sj/historysj/{YYYYMM}/zip/{YYYYMM}.zip`
  ——**按月一个 zip、内含每个交易日的全合约 csv**，字段含 合约代码/开/高/低/收/结算/前结算/成交量/持仓量。
  覆盖 2010-04（IF 上市）至今。落地 `cn_index_futures/data/cffex_daily.parquet`。
- 指数现货对照：`akshare.stock_zh_index_daily`（sh000300 / sh000905 / sh000016 / sh000852），
  用于分解「期货隔夜收益 = 指数隔夜收益 + 隔夜基差修复」。
- 幸存者偏差：期货合约天然全部到期，本卡用「逐日按前一日持仓量最大的合约」定义主力，
  **含所有已到期合约**，不存在按表现挑合约的空间。

## 5. 口径锁死（写完不许再改）

- **策略角色**：alpha（制度约束套利），不是 hedge。
- **宇宙**：IF（2010-04-16 起）、IH/IC（2015-04-16 起）、IM（2022-07-22 起）四个品种，
  每日各取「前一交易日持仓量最大」的合约为主力（PIT，只用 ≤ t−1 的持仓量）。等权分配名义。
- **成本（锁死，全程不许调）**：**单边 1.0bp 名义**
  = 中金所手续费 万分之 0.23（开仓/平昨，非平今）+ 滑点 1 跳（IF≈0.5bp、IH≈0.7bp、IC/IM≈0.35bp）。
  每晚 2 单边 = 2.0bp；按 250 夜/年 = **年化 5.0%**。压力档 2× = 10.0%/年。
- **调仓频率**：每交易日 2 次（收盘开、次开平），年化单边换手 500 次。
- **基准**：现金（零收益）。附报 ① 对指数现货的 β 与 CAPM alpha；② 「一直做空全天」的静态对照。
- **目标函数与判读线**：日频资金曲线净年化 > 0 且 NW t ≥ 2；且 2019-2026 段单独 > 0；
  且随机时移置换分位 ≥ 95%；且最大回撤 ≤ 20%。任一不满足 → FAIL/PARK。
- **信息→决策→成交→PnL**：
  `information_time = t 日 15:00 收盘（收盘价与 t−1 日持仓量均已知）`
  → `decision_time = t 日 15:00`
  → `execution_time = t 日收盘价开空 / t+1 日 09:30 开盘价平仓`
  → `pnl_start = t 日收盘` → `pnl_end = t+1 日开盘`。
  **无任何跨日信号，不存在 shift 争议**；风险在于收盘价与开盘价能否成交，见压力档。
- **压力成本与容量**：IF 单日成交额数百亿元，收盘/开盘集合竞价均有深度，容量不是约束。
  压力档把成本翻倍到 10%/年。
- **尝试账本（trials）**：本卡只跑**一个**预注册规格（等权 4 品种、收盘开空次开平）。
  A 层的品种分解与分段（2017-2021 / 2022-2026）属于**描述性诊断**，不构成参数搜索。

## 7. 验收结果（quant-backtest-protocol 研究漏斗）

**结论：死在 A 层，没有进入 B 层。** 载体本身的隔夜收益是**正的**，做空它连毛边际都没有。

| 层 | 问题 | 结果 | 判定 |
|---|---|---|---|
| A 成本闸（事前） | 用 H0028 的现货指纹当毛边际（隔夜 −11.17%/年，做空毛 +11.17%）| 毛/成本 = **2.23**，压力档 1.12 | **THIN**（`out/screen_exante.json`）——允许往下做，但成本必须锁死 |
| A 成本闸（实测载体） | 换成**期货合约自身**的隔夜毛边际 | 等权毛年化 **−9.99%**，毛/成本 = **−2.00** | **STOP**（`out/screen.json`）→ 直接 FAIL |
| A 谁付钱 | 假设的付钱者是被 T+1 锁住的隔夜持有者 | 在**现货**上确实存在；在**期货**上不存在（见下） | 机理转移失败 |
| A 载体毛边际 | 同合约夜 `open(t+1)/close(t)−1`，主力按 t−1 持仓量选 | IF **+4.06bp/夜**(NW t=+4.22)、IH **+4.79**(+3.85)、IC **+5.82**(+4.35)、IM **+4.54**(+1.82) | **四个品种全为正**，与假设方向相反 |
| A 分段稳健 | 2010-2015 / 2016-2018 / 2019-2026 | IF +3.27 / +5.33 / +4.16 bp/夜；IH +15.18 / +5.12 / +3.64；IC +23.27 / +3.25 / +5.16 | **没有任何一段是负的** |
| B 数据因果 | 决策是否只用 ≤t 的信息 | 无条件每晚交易、无参数；主力选取用 `open_interest.shift(1)`。分辨力检验：改用当日持仓量会有 **3.4%~5.3%** 的日子选出不同合约 | PASS（`out/causality.json`）|
| B 成交时序 | information→decision→execution→pnl | `t 日15:00收盘（t−1持仓量已知）` → `t 日15:00决策` → `t 日收盘价开空 / t+1 日09:30开盘价平仓` → `pnl: t收盘→t+1开盘`。**每晚在同一张合约内结算，换月不进 PnL** | PASS |
| B 可交易性 | 换手、成本、压力档 | 500 单边/年 × 1.0bp = 5.0%/年；压力档 10.0%/年。只走平昨档（万分之0.23），不触发平今（万分之3.45） | 成本假设成立，但无毛边际可覆盖 |
| C 归因 / DSR / 自助 / 置换 / 稳定 | — | **未做**：A 层 STOP，按协议不进 B/C 层 | 不适用 |

**假设方向（做空隔夜）的组合结果**（等权 4 品种，3,826 夜，2010-04-19~2026-09-03）：

| | 毛 | 净（2bp/夜） |
|---|---|---|
| 年化 | **−9.99%** | **−14.42%** |
| 日频夏普 | −1.06 | −1.59 |
| NW t | −4.26 | −6.39 |
| 最大回撤 | −81.4% | −91.3% |
| 2019-2026 段年化 | −10.18% | −14.60% |

**死因的机理分解（`out/basis_decomp.json`，恒等式残差 0.03~0.22bp，逐项对得上）**：

`期货隔夜收益 = 指数隔夜收益 + (今开基差 − 昨收基差)`

| 品种 | 指数隔夜 | 隔夜基差修复 | = 期货隔夜 | 收盘基差均值 |
|---|---|---|---|---|
| IF | −6.04bp | **+10.07bp** | **+4.06bp** | −0.26% |
| IH | −5.45bp | **+10.19bp** | **+4.79bp** | −0.27% |
| IC | −6.32bp | **+11.93bp** | **+5.82bp** | −0.98% |
| IM | −4.09bp | **+8.54bp** | **+4.54bp** | −1.08% |

**读法**：现货指数每天开盘确实低开（−4~−6bp，这就是 T+1 折价），但期货在**前一天收盘时
就已经把这个低开贴进了基差**——收盘基差比次日开盘基差深 8.5~11.9bp。
第二天开盘基差修复的这一段，比指数的低开还多，于是期货自身的隔夜收益转为正。
**T+0 的套利者把这笔钱在收盘前就赚走了，留给隔夜空头的是负数。**

## 8. 裁决

**FAIL —— 方向反了。**

不是成本吃穿（虽然 `qr screen` 的提示语默认这么写）：**毛边际本身就是负的**，
成本只是把 −9.99% 变成 −14.42%。也不是不可成交、不是未来函数、不是幸存者偏差
（因果闸过、成交时序清晰、期货合约天然全样本）。

## 9. 留给后人的一句话

**「A 股现货上有个异象，我用股指期货去做」——动手前先算一件事：这个异象是不是已经在基差里了。**
本卡是这句话的第一个实例：T+1 造成的隔夜折价在现货上真实存在（−4~−6bp/天，H0028 在个股上量到年化 −21.7%），
但**股指期货是 T+0，套利者在收盘前就把它压进了贴水**，于是期货自身的隔夜收益反而是正的
（四个品种 +4.06~+5.82bp/夜，NW t 全部 ≥ 3.8，2010-2026 没有一段为负）。
做空期货隔夜段毛年化 −9.99%、净 −14.42%、最大亏损九成。

**三条可直接复用的结论：**

1. **H0028 那句「A 股不能做空，这一格拿不到钱」现在可以补完整了**：
   不是"没有能做空的载体"，而是**唯一能做空的载体上这个异象不存在**——
   因为它能做空，所以它把异象套没了。这是一个自洽的均衡，不是遗漏。
2. **逐夜策略天然免疫换月，但换月夜的收益绝对不能算进去**：
   t 日收盘开的仓、t+1 开盘平的是同一张合约，跨合约收益根本不进 PnL。
   本卡实测**换月夜的"隔夜收益"是 −16bp（IH）到 −104bp（IC）**，
   IC 换月夜的伪收益是正常夜的 20 倍——**任何用主力连续序列算跨日收益的做法都会被这个数污染**
   （H0013 死在这里）。判据很简单：比较相邻两天的合约代码，不同就丢掉这一夜。
3. **反方向（做多隔夜）留给后人一条真线索，但别高兴太早**：
   等权四品种、同样 2bp/夜成本，净年化 **+4.68%**、夏普 0.53、NW t 2.13，
   **对同池四指数等权的 β = −0.007（几乎完全市场中性）**、剥 beta 后 alpha +5.06%/年(t=2.13)。
   17 个自然年里 13 年为正。**但它靠 2015 撑着**：剔掉 2015 一年，alpha 掉到 +3.26%/年、**t=1.46（不过线）**。
   机理上它赚的是「收盘基差被砸深、隔夜修复」这一段，付钱者大概率是**尾盘建/调空头对冲仓的中性产品**——
   这个付钱者是否稳定、是否会随中性产品规模变化，是开子卡前必须先回答的问题。
   开卡前还欠：DSR、换手匹配置换、分块自助、以及「收盘价与开盘集合竞价能否真的成交」的滑点压力档。

数据侧留一句：**中金所官网限流很凶**（一个月的 zip 要 30 秒起，全量 198 个月并发 8 线程仍跑了 40 分钟），
新浪的单合约日线只保留最近约 3 年但**开盘价与官网完全一致**（重叠 7,864 行，open 最大差 0.0000），
两者合并是目前拿到 2010-2026 全样本最省时间的路子。详见 `markets/cn_index_futures.md` §3。
