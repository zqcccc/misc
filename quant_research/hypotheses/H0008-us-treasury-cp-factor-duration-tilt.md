# H0008 · 美债远期利率的 Cochrane-Piazzesi 帐篷形因子（用财政部日收益率曲线滚动扩张窗实时估计）能正向预测下月国债超额收益，据此做月度久期三档倾斜，在锁死成本下日频资金曲线夏普与净 alpha 优于固定久期的同池等权债券组合

## 1. 假设（一句话，可证伪）
> 在 SHY / IEF / TLT 三只美国国债 ETF 构成的池子上，**Cochrane-Piazzesi 帐篷形远期利率因子**
> （用美国财政部每日收益率曲线、以滚动扩张窗实时估计载荷，只用 t 及之前数据）
> 对**下个月的国债超额收益**有**正向**时序预测力；据此做月度久期三档倾斜，
> 在单边 3bp 成本下，**日频资金曲线夏普与对同池等权组合的净 alpha 均优于固定久期的同池等权组合**。

## 2. 机理（为什么应该成立）
**风险溢价（时变期限溢价）**，不是数据挖掘。
链条：预期假说失败 → 远期利率不只是未来短端利率的预期，还包含**随时间变化的风险补偿**；
Fama-Bliss(1987)、Campbell-Shiller(1991) 先证伪了"远期利率是无偏预期"；
Cochrane-Piazzesi(2005) 进一步发现这个风险补偿是**一维的**：1~5 年期一年远期利率的一个
线性组合（载荷呈"帐篷形"，峰值在 3 年期附近、两端为负）就能解释各期限债券次年超额收益
R² 0.32~0.44。经济含义：债券风险溢价是一个共同的、随时间波动的状态变量；
当 CP 因子高时，持有长久期债券的下月预期超额收益更高 → 拉长久期。
**机制方向先验已锁定（β>0），本轮不搜方向、不搜载荷形状。**

## 3. 先验检索（动手前必做，写结论不写过程）
- **正面**：CP(2005, AER) 原始结果 R² 0.31~0.44，载荷帐篷形，跨期限一致。
  后续：Ludvigson-Ng 宏观扩展、Cieslak-Povala 周期分解、「Reconstructing the yield curve」
  (JME 2021) 用核平滑曲线**复现了 CP 的稳健载荷形态**，并支持"未被收益率曲线 spanned 的因子"。
- **负面（找到了，这才是关键）**：
  1. **Duffee (2011) "hidden factor" 批评**：收益率曲线本身不足以预测债券风险溢价，
     存在未被 spanned 的隐藏因子 → 纯曲线信号的信息可能不完整。
  2. **Bauer & Hamilton (2018)**：除三个收益率主成分之外的变量（含 CP 的高阶成分）
     对超额收益的预测证据"不令人信服"，对 CP 类预测性回归的小样本推断提出质疑。
  3. **Duffee (2011) / Barillas (2011) / Adrian et al. (2013) / Joslin et al. (2014)**：
     仅用收益率的动态期限结构模型**无法**捕捉债券风险溢价的可预测性 → 样本外经济价值存疑。
  4. 上一条直接意味着：**本假设最可能死在"样本外 alpha ≤ 0"或"DSR 不显著"这一环**，
     而不是死在未来函数或成本。写卡时就把这个预期写下来，不许事后改口径去救。
- **与台账相邻 ID**：H0004 / H0005（us_stock / timing，claude 与 trae 活跃占坑）。
  区别：市场不同（rates vs us_stock）、信号不同（远期利率期限结构 vs 信用利差 / VIX 期限结构）、
  标的池不同（国债 ETF vs SPY）。机理族同为 timing，但**台账里 rates 市场是零覆盖格**。
  H0004/H0005 是别人的活跃占坑，本轮只读不写。

## 5. 口径锁死（写完不许再改）
- **宇宙 / 可投池规则**：固定 3 只，**不再增删、不许按表现替换**：
  `SHY`（1-3Y，久期≈1.9）、`IEF`（7-10Y，久期≈8.0）、`TLT`（20+Y，久期≈17）。
  全部用 **Adj Close（后复权总收益）**；权重 ∈ [0,1]、权重和恒为 1，**禁止杠杆、禁止做空**。
  无幸存者偏差问题（三只至今仍在交易，池子不按表现增删）。
- **成本**：**单边 3bp（双边 6bp）**，含佣金 + 买卖价差 + 冲击，锁死全程不调。
  （口径与 `markets/us_stock.md` 的超大盘 ETF 3bp 一致，不另设一个更好看的数。）
- **调仓频率与持仓数**：**月度**，每月最后一个**共同交易日**收盘发信号、收盘成交；
  恒持 3 只，允许权重 0 但不允许只持 1 只（禁止把久期倾斜做成空仓择时——那会引入额外的市场择时 beta）。
- **信号构造（严格 PIT）**：
  1. 由财政部日曲线插值出 1/2/3/4/5 年期**一年远期利率** f1..f5；
  2. 每月末用**截至该月末**的历史月度数据做**扩张窗** OLS：
     `rx_{t→t+1}(平均久期组合) = γ0 + γ1 f1 + γ2 f2 + γ3 f3 + γ4 f4 + γ5 f5 + ε`；
  3. `CP_t = γ' f_t`；预热期（<60 个历史月）不交易，保持等权。
- **仓位规则（零自由参数）**：按 `CP_t` 在**扩张窗历史分布**中的**三分位**切三档：
  - 高档（CP 高 → 预期超额收益高 → 拉长久期）：`TLT .50 / IEF .30 / SHY .20`
  - 中档：`各 1/3`
  - 低档（压低久期）：`SHY .60 / IEF .30 / TLT .10`
  - 三分位分界用**截至 t 的历史**（无未来函数）；档位 = 该月唯一状态，不叠加其他过滤。
- **基准**：**主基准 = 同池等权组合**（SHY/IEF/TLT 各 1/3、月末再平衡、同样扣 6bp 双边成本）。
  这是"固定久期"的对照组——跑不赢它说明"择久期"这一步没加分。
  附报对照：`AGG`（全债指数）、`^IRX/12`（现金）。**不用 SPY 当基准**（跨资产，会把久期收益和股票 beta 混在一起）。
- **三段切分**：TRAIN 2007-12~2017-12 ／ VALID 2018-01~2021-12 ／ **TEST 2022-01~2026-08（加息熊市，与训练期性质不同，诚实压力测试）**。
  TEST 只揭盲一次。
- **目标函数与判读线**：以**日频资金曲线**为准（252 年化夏普）。
  PASS 需同时满足：对同池等权的净 alpha 的 **NW t ≥ 2**（lag=6）**且 DSR ≥ 0.90 且 随机组合置换分位 ≥ 95%**。
- **试验轮数 trials（预先登记，全部计入 DSR）**：主口径 1 + 敏感性网格 4（载荷：扩张窗重估／原文固定帐篷载荷 × 分档：三分位／中位数二分位）+ 延展样本对照 1（用曲线合成收益、样本 1995-2026）= **N = 6**。
  除此之外不再跑任何变体；多跑一个就多记一个 trials。

## 8. 裁决

**FAIL —— 死在「信号没有增量信息」这一环（不是未来函数、不是成本、不是不可成交）。**

三条独立证据指向同一结论：
1. **机理没复现**：CP 帐篷形载荷在 2002-2026 的财政部 CMT 口径下**没有出现**。
   1 个月持有期全样本 R²=0.061，载荷 γ=[−0.01, +0.57, −1.55, +0.42, +0.79]（峰值本该在 f3 且为正，实测 f3 最负）；
   换成 CP 原文的 12 个月持有期 R²=0.260，载荷 γ=[+1.87, −2.31, −4.88, +2.37, +4.44]，同样不是帐篷形。
   原文 0.44 的 R² 依赖 Fama-Bliss 零息曲线与 1964-2003 样本；**2003 年之后这一段不成立**。
2. **排名规则退化**：CP 水平值在 2002→2020 单调下行（分年均值 189→37，之后回升），
   扩张窗分位排名在趋势序列上退化成「68% 时间停在短久期档」（L157/M64/H10，231 个月只切换 42 次）。
   平均权重 SHY 0.509 / IEF 0.309 / TLT 0.182 ≈ 一个静态短久期组合。
3. **静态对照反杀**：拿掉信号、恒定持有 W_LOW，在 FULL 与 TEST 两段的夏普都**高于** CP 择时。
   对同池等权那 +1.1%/年的表观 alpha，全部是静态短久期暴露，不是择时。

补 B 那个 84.6% 胜率不救它——比的是带长久期偏置的等权基准，赢的是久期暴露不是信号。

## 9. 留给后人的一句话

**在财政部 CMT（恒定期限票面）收益率曲线上做 CP 因子择时，这条路死了**，两条具体的坑：
① CMT 是**票面**收益率，直接当零息用会把远期利率算出 −261% 这种数，必须先自举零息曲线（本卡 §6 有现成实现）；
② 自举之后 R² 也只有 0.06~0.26 且**载荷不是帐篷形**——CP 的 0.44 是 Fama-Bliss 零息曲线 + 1964-2003 样本的产物，
不要在 2003 年后的样本上指望它。
更普适的一条：**用"扩张窗历史分位"给一个长期趋势序列分档，会退化成静态偏移**；
跑完信号先算一下平均权重和档位分布，如果一个档占了 2/3，你做的就不是择时，
下一步必须拿"静态同权重对照"去打，不然会把自己骗过去。
