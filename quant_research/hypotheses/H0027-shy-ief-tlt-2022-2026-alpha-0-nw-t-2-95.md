# H0027 · 财政部已公布拍卖需求与收益率曲线的浅层扩张窗随机森林，每月在 SHY/IEF/TLT 中选一只；2022-2026 净收益相对月度等权的年化 alpha>0、NW t>=2、匹配换手循环移位置换分位>=95%

## 1. 假设（一句话，可证伪）
> 只使用调仓时已经公布的美国国债票息券拍卖需求和收益率曲线，固定的浅层扩张窗随机森林每月在 SHY、IEF、TLT 中选择下一月总回报概率最高的一只；在单边 3bp 成本下，2022-01-01 至最新完整交易日相对同池月度等权基准的年化 alpha > 0、Newey-West t ≥ 2，且匹配持仓分布和换手的循环移位置换分位 ≥ 95%。

## 2. 机理（为什么应该成立）
- 制度约束：美国财政部按预定日程拍卖，一级交易商承担做市与承销义务。一级交易商被迫承接的比例越高，代表真实终端需求越弱、库存与对冲压力越大；间接投标人承接比例与投标倍数则提供相反的需求信息。
- 风险溢价：相同的拍卖需求冲击在不同曲线水平、斜率和曲率下，对短中长期债券的久期补偿并非线性；浅层树只承担这组预先指定交互，不从价格技术指标里自由挖形状。
- 可交易落点：SHY/IEF/TLT 把短、中、长久期映射为三个高流动性 ETF；月频决策让 3bp 单边成本相对预期月收益有余量。

## 3. 先验检索（动手前必做，写结论不写过程）
- 正证据：Bianchi、Büchner、Tamagno 的 *Bond Risk Premia with Machine Learning* 发现机器学习纳入收益率以外的预测变量可改善债券超额收益的样本外预测；ECB 工作论文 *Trading Ahead of Treasury Auctions* 给出拍卖前可预测价格下跌、交易商用期货对冲预期供给冲击的机制证据。
- 负证据：*Understanding determinants of bond excess returns using explainable AI* 报告只用收益率曲线主成分时，随机森林与 ExtraTrees 在各期限的样本外 R² 均为负，长端神经网络亦为负；因此本卡不把“用了 ML”视为优势，必须证明拍卖信息相对同池等权有经济增量。Quantocracy 近 14 日路线 A 扫描返回空输出；arXiv/网页定向检索未发现与“公开拍卖结果 + 三只 ETF 月度久期选择”完全相同的可复现实验。Reddit/GitHub 没有找到可作为主证据的严谨复现，不把未命中写成没人做过。
- 官方数据可得性审计：Fiscal Data API 无需 key；2002–2007 的投标人分类字段为空，2008 年部分可用，2009 年起所选票息券完整。API 会预先列出未来拍卖，必须排除运行日之后的记录，并要求结果字段非空。
- 与 H0008 相邻但不重复：H0008 仅用收益率曲线远期变化做规则择时，最终退化成静态短久期；本卡的新增原始信息是投标倍数、间接投标人与一级交易商承接比例，并用预注册浅层模型检验其增量。H0021 用 VIX 期限结构择时债券风险，不使用拍卖需求。

## 4. 数据需求
- 拍卖：Fiscal Data `auctions_query` API，2009-01-01 起，仅 `security_type ∈ {Note, Bond}` 且原始期限为 2/3/5/7/10/20/30 年；字段 `auction_date, security_term, bid_to_cover_ratio, indirect_bidder_accepted, primary_dealer_accepted, total_accepted, offering_amt`。排除未来日期和任一核心字段为空的记录。
- 曲线：美国财政部 CMT 日数据的 2Y、5Y、10Y、30Y；每次调仓只取严格早于调仓交易日的最后观测。构造 10Y 水平、10Y−2Y 斜率、30Y−10Y 长端斜率、`2×5Y−2Y−10Y` 曲率。
- 资产：Yahoo Finance `auto_adjust=False` 的 SHY/IEF/TLT `Adj Close` 日线，2009-01-01 至最新；仅用相邻收盘总回报。不得读取本仓库 H0008 的现成完整测试缓存，以新下载副本按日期拆分。
- 拍卖特征：以每个预测月之前 3 个完整日历月为窗，把期限分为短（2/3Y）、中（5/7/10Y）、长（20/30Y）三桶；每桶固定构造投标倍数中位数、`Σ间接承接/Σ总承接`、`Σ交易商承接/Σ总承接`，共 9 项，加 4 项曲线状态，共 13 项。不得增加、删除或按结果挑选特征。
- 三段：TRAIN 2009-01-01~2018-12-31（前 60 个已完成月仅作模型预热）；VALID 2019-01-01~2021-12-31；TEST 2022-01-01~运行日之前最后完整数据。下载时把 TEST 原始拍卖、曲线、ETF 文件直接写到工作区外的独立目录；开发阶段只读 TRAIN/VALID，规则冻结后一次揭盲。

## 5. 口径锁死（写完不许再改）
- 宇宙 / 可投池规则：固定 SHY、IEF、TLT 三只，不按当前可得性回填、不加新 ETF、不做空、不加杠杆、不持现金。三只在 2009 年前均已上市，固定历史池不产生样本期内上市/退市选择。
- 模型：主模型固定 `RandomForestClassifier(n_estimators=300, max_depth=2, min_samples_leaf=12, max_features='sqrt', class_weight='balanced', random_state=20260904)`；每个调仓月扩张窗重训，不用 TEST 调参。标签为下一个持有月从首次建仓收盘到下次调仓收盘三只中总回报最高者；训练时只纳入结果已结束的月份，至少 60 个标签。预测概率最高者入选；完全并列按 SHY→IEF→TLT 固定顺序。只附报固定 Logistic（标准化仅在当期训练窗拟合）和同深度 ExtraTrees 两个敏感性模型，不据其结果换主模型，DSR trials 锁死 N=3。
- 成本（单边 bp，含税费滑点）：3bp；首次从现金建仓按换手 1 扣 3bp，以后按调仓收盘时漂移权重到新权重的 `Σ|w_new−w_old|×3bp` 扣费。策略从一只换另一只是 6bp；基准同样按月重置 1/3 并按实际漂移换手扣费。
- 调仓频率与持仓数：每月第一个共同交易日收盘生成并执行信号，随后一个交易日起持有 1 只至下月调仓收盘；仅使用调仓收盘前已知的数据，不假定能赚到生成信号当天的收盘收益。若必要输入缺失则沿用上月仓位，不做事后填充，并记录阻塞。
- 基准（同池等权 + 指数对照）：主基准为同三只 ETF 每月第一个共同交易日收盘重置等权、同成本；附报 SHY/IEF/TLT 各自同期买入持有，以及策略 TEST 平均权重对应的静态固定权重组合（同首次入场成本），防止“机器学习”只是静态久期偏置。
- 目标函数与判读线：不搜参，VALID 只作冻结前体检而不选模型。主考卷为 TEST 日频净资金曲线：相对主基准年化 alpha > 0 且 Newey-West t≥2、DSR≥0.90、5000 次分块自助绝对赚钱概率≥10%、5000 次按月循环移位的信号置换（保持三类持仓占比并近似匹配换手）分位≥95%，逐年剔除后 alpha 均为正；策略收益和夏普还须同时胜过同池月度等权及静态平均权重组合。任一硬门失败即 FAIL；若统计过线但成交阻塞比例不可验证或 TEST 隔离被破坏，最多 PARK。

## 8. 裁决
`PASS` alpha t≥2 且 DSR≥0.90 且置换分位≥95% ｜ `FAIL` 证伪 ｜ `PARK` 有信息但不具备上仓位条件/数据不足

**FAIL。** 预注册随机森林在独立验证期把一个年化赚 5.11% 的同池等权组合做成了年化亏 1.71%；剥掉共同债券涨跌后每年少 4.39%，且静态持有相同平均久期也能年化赚 4.15%。第一道经济检验已经证伪，按顺序停止，未用 2022–2026 TEST 为失败模型做二次机会。

## 9. 留给后人的一句话
可复用的正面或负面结论。**负面结论同等重要——它就是别人不用再走一遍的那条路。**

别再直接用“过去三个月国债拍卖投标倍数 + 间接/交易商承接比例 + 当期曲线”训练浅层三分类模型做 SHY/IEF/TLT 月度择一：2009 后字段虽完整且因果对齐无泄漏，但 2019–2021 的切换把静态同久期组合约 4.2% 的年化收益做成约 −1.7%；若重开，应先研究拍卖日附近的连续期限收益或交易商库存冲击，而不是把稀少的 IEF 最优月份硬压成三分类。
