# H0202 · 在外汇市场（G10 9大货币 vs USD，2004-2026日频）上，实行事前锁死的抽稀载体：按货币代码字母序分成三组（aud/nok/nzd、cad/nzd…固定映射），每个20交易日调仓期只持有轮到的那一组等权、其余持现金，持仓轮换调度只由调仓序号与日期决定（与货币自身过往表现无关），在单边2.0bp锁死成本下，资金曲线相对同池等权多头年化净增量>0且NW t>=2——G10外汇分组抽稀与再平衡成本检验（fx×seasonality空白格）

## 1. 假设（一句话，可证伪）
> 在 G10 九大货币对 USD 的日频面板（2004-2026）上，把货币按代码字母序固定分成三组，
> 每个 20 交易日调仓期只等权持有轮到的那一组、其余持现金（轮换调度 = 调仓序号 × 13 + 调仓日月份 模 3，
> 与货币自身过往表现无关），在单边 2.0bp 锁死成本下，资金曲线相对同池等权多头的年化净增量 > 0 且 NW t ≥ 2。

## 2. 机理（为什么应该成立）
**无独立机理，本卡是载体层面的检验，写明：只有载体效应，没有信号。**

真正的问题是「外汇截面策略的可行性下限在哪里」：H0200（quality）与 H0201（lowvol）都在 A 层被成本吃掉，二者都靠高换手去赚一个接近零的截面价差。本卡把换手来源整个拿掉——只留分组、只留调仓节律，看**降低换手能不能把一个零期望的货币多头摊成可交易超额**。

判定逻辑很直接：抽稀必然让组合波动低于九币等权。若波动降下来而超额没有，就说明低换手本身不产生溢出价值，外汇的截面超额只能来自方向（carry、政策差），不能来自摊薄。点差水平与仓位对照的设计细节放在 §3 与 §5。

## 3. 先验检索（动手前必做，写结论不写过程）
- **负面证据是主线**：本卡不搜「外汇季节性因子有效」，只查「降低换手、减少持仓数能否提升风险调整后收益」。文献共识是抽稀降低的是波动而不是收益，在零期望的多头上等价于同步缩小分子与分母（Sharpe 不变、超额同比例缩小），对摩擦只会更不利。
- 点差与仓位对照：G10 主要货币点差 0.2-5bp，2bp 单边是保守上限。对照基准用「同池全货币等权多头」而不是「恒定持 1/3 仓位的静态对照」——本卡要回答的是「抽稀载体相对满仓多头有没有增益」，若改用同仓位对照，就变成「选哪一组」的问题，而分组已被证明确由种子决定符号，没有可检验的内容。空仓部分的资金按零收益计，这与满仓基准的对比是同一口径。
- 台账内相邻三张：H0200（fx quality，成本吃穿）、H0201（fx lowvol，成本吃穿）、H0159（港股月末年初 TOM，日历效应 FAIL）。三者都用「方向信号 + 短期持有」，本卡把方向信号整块拿掉，只测载体。与 H0168（多市场 Sell-in-May）的差别在于标的是货币不是股指、且调度不依赖月份本身，也不预设「某半年该空仓」。

## 4. 数据需求
G10 九大货币对 USD 日频收盘（aud cad chf eur gbp jpy nok nzd sek），2004-01 起，AUD 2006-05 起动态进入。数据在仓库根的 `fx/data/fx_<sym>.csv`（单列收盘价），读取统一走 `quant_research/fx/lib.py`（其 `DATA = Path('fx/data')` 是相对仓库根的路径）（反报价换算、坏点单条件标记、无跨日回填），无需外部取数。

## 5. 口径锁死（写完不许再改）
- 策略角色（alpha / diversifier / hedge / execution）：execution（检验低换手载体本身能否摊出超额，不承担方向信号）
- 宇宙 / 可投池规则：G10 九币 vs USD；调仓日 `d0` 当日无真实报价的货币剔除；分组按**代码字母序索引 % 3**（aud/nok/nzd 等固定映射，事前锁死）
- 成本（单边 bp，含税费滑点）：单边 2.0bp，压力档 ×2 = 4.0bp
- 调仓频率与持仓数：每 20 交易日调仓一次；每期持有一组（约 3 只）等权，其余现金
- 基准（同池等权 + 指数对照）：同池当日全部可投货币等权多头
- 目标函数与判读线：相对同池等权多头的年化净增量 > 0，且 NW t ≥ 2；A 层要求毛/成本 ≥ 2
- 信息→决策→成交→PnL：`d0` 收盘用当日收盘价定组 → 收盘成交 → PnL 区间 `d0` 收盘到 `d1` 收盘，窗口内缺报价日在该币连乘链里跳过（`lib.compound` 的 skipna 口径）
- 压力成本与容量假设：G10 点差 0.2-5bp，2bp 单边对主要货币是保守上限；每期 3 个持仓，容量不受限
- 尝试账本（参数/过滤器/区间/失败变体都计入）：共 5 个变体，全部计入 Trials——①分组调度 `group = 字母序索引 % 3`、`slot = (调仓序号 * 13 + 调仓日月份) % 3`（即 run.py 采用的最终口径）：gross 0.86%/NW t 1.23/换手 12.49 次单边；②不依赖日期、`slot = 调仓序号 % 3`（探针 `probe/fx0299_probe.py` 的 scheme 0）：gross 0.87%/NW t 1.63/换手 2.02；③`slot = (调仓序号 + 1) % 3`（scheme 1）：-0.02%；④`slot = (调仓序号 + 2) % 3`（scheme 2）：-0.86%；⑤去尾 1%/2%/5% 三档。②③④ 只差一个相位偏移，毛收益符号就完全翻转，说明收益由轮换相位决定、不是可重复的载体效应；因此本卡不挑最好的相位，按最终口径（①）如实裁决。探针脚本留在 `quant_research/fx/h0202/probe/`（已 gitignore），随时可复算②③④。

## 8. 裁决
`FAIL`（死因：强度不足）
G10 九大货币按字母序固定分三组、每 20 交易日轮持一组，二十二年 289 期毛年化 0.86%，扣除单边 2bp（年化 0.250%，换手 12.49 次单边）后净 0.61%，毛/成本 3.45 通过 A 层成本闸（2 倍压力档 0.36% 仍为正）；但 NW t = 1.234 不显著，前后两段 1.15%（t=1.31）/ 0.57%（t=0.53）都站不住，去尾 5% 转负。同期九币等权多头年化 0.30%，抽稀高出的部分在统计上分辨不出。

## 9. 留给后人的一句话
外汇市场的低频超额只能来自方向（carry、政策差），不来自降低换手：把九币多头抽稀到三分之一持仓，波动从约 7% 降到 3.48%，毛收益也同步缩到 0.86%，扣掉 0.25% 摩擦剩 0.61%，统计上分辨不出。要检验载体，先确认被装载的多头本身有肉；零期望的多头无论怎么摊薄都摊不出超额。
