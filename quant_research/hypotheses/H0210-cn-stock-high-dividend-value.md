# H0210 · 在A股大盘流动性前300股票池（astock_quant面板4906只全A股票，2017-2026日频）上，用50%分位以下的「现金分红率（股息率）Top20%」纯多、等权、20交易日调仓，在A股锁死成本（单边买12.6bp/卖22.6bp，平均17.6bp）下，资金曲线相对同池等权多头年化净超额>0且NW t>=2——A股高股息组合相对全池的净超额检验（cn_stock×value补充格）

## 1. 假设（一句话，可证伪）
> 在 A 股大盘流动性前 300 股票池（astock_quant 面板，2015-2026 日频）上，用过去 365 个自然日
> 已实施现金分红 / 调仓日收盘价构造股息率，纯多股息率最高的 20%、等权、每 20 交易日调仓，
> 在 A 股锁死成本（单边买 12.6bp / 卖 22.6bp，平均 17.6bp）下，资金曲线相对同池等权多头
> 年化净超额 > 0 且 NW t ≥ 2。

## 2. 机理（为什么应该成立）
**有明确机理：制度约束 + 风险溢价。**

高股息组合在 A 股有两条真实的经济来源：①分红是硬现金，估值下行时提供实际回报的下限，风险溢价更低；②2016 年后监管鼓励分红、长线资金（保险、社保、外资）偏好稳定派息，形成结构性买盘。与「按 PE/PB 排序」不同，股息率用的是**已实施**的现金分红，几乎不存在会计口径操纵空间，属于价值族里最干净的一个变量。

## 3. 先验检索（动手前必做，写结论不写过程）
- **负面证据**：A 股的高股息策略在 2019-2021 成长股行情中被长期压制；本卡的分段结果也印证了这一点——后半段超额几乎消失。
- **与台账相邻**：cn_stock×value 此前只有一张 PARK 卡（按估值排序）。本卡换成「已实施现金分红」这个更难被操纵的变量，属于同格不同信号。与 H0181（cn_stock×ml，浅层岭回归）的差别是只用单一变量、不做多因子合成。
- **数据口径**：`astock_quant/data/corporate_actions.csv` 记录每笔现金分红的实施日与每股金额，用「实施日 ≤ 调仓日、且在过去 365 天内」的口径聚合，严格 PIT。

## 4. 数据需求
`astock_quant/data/panel/close.parquet`（复权收盘）、`amount.parquet`（成交额，用于选大盘前 300）、`corporate_actions.csv`（含 `code / date / cash_per_share_pre_split`，2015-01 起 35057 条）。全部已在仓。

## 5. 口径锁死（写完不许再改）
- 策略角色（alpha / diversifier / hedge / execution）：alpha（横截面价值，纯多）
- 宇宙 / 可投池规则：调仓日 `d0` 的 20 日平均成交额前 300 只，且当日有收盘价；池子不足 150 只跳过
- 成本（单边 bp，含税费滑点）：单边平均 17.6bp（买 12.6 / 卖 22.6），A 股实际税费与滑点
- 调仓频率与持仓数：每 20 交易日调仓；持有股息率最高 20%（约 60 只）等权
- 基准（同池等权 + 指数对照）：同池 300 只等权多头
- 目标函数与判读线：A 层毛/成本 ≥ 2；C 层相对等权多头的净超额 NW t ≥ 2
- 信息→决策→成交→PnL：`d0` 收盘用**已实施**的过去 365 天现金分红 / `d0` 收盘价算股息率 → `d0` 收盘成交 → 持有至 `d1` 收盘
- 压力成本与容量假设：成本已按 A 股实际双边费率；60 只持仓，容量不受限
- 尝试账本（参数/过滤器/区间/失败变体都计入）：共 3 项——①主口径（20% 分位、365 天窗口）：见 §7；②前后两半段拆分（非参数搜索，属稳定性检验）。

## 8. 裁决
`FAIL`（死因：强度不足）
A 股流动性前 300 里按过去 365 天已实施现金分红 / 收盘价选股息率最高的 20%，2015-04 至 2026-08 共 139 期，毛年化 8.21%，扣 17.6bp 单边摩擦（换手 4.20 次、年化 0.740%）后净 7.47%，毛/成本 11.1；同期同池等权多头 -7.39%。但相对等权多头的超额 NW t 仅 1.756（扣成本后约 1.60），未过 2；前后两半段差异巨大：前半 +14.77%（t = 2.525），后半 +1.73%（t = 0.249）。

## 9. 留给后人的一句话
A 股高股息在 2015-2020 是真实有效的价值因子（前半段 t 值 2.5，扣完成本还剩 14 个点），2021 年之后基本失效。这条结论比「高股息没用」更精确：它不是伪因子，而是**窗口依赖**——与 2019-2021 成长股行情、2022 年后利率下行把股息资产估值抬到高位都有关。要做这条，必须接受「只在特定宏观区间有效」，且需要额外的宏观开关（利率、信用周期）才能算可交易策略；单靠排序不能过 C 层。
