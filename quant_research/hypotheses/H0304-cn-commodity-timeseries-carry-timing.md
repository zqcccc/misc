# H0304 · 在中国商品期货主力连续（SHFE/CZCE/DCE/GFEX，2016-2026 逐合约拼接主力，剔除 H0057 换月价差跳变）上，做时序期限结构 carry 择时：每品种用近月对次近月年化贴水 (F_near/F_far-1)*365/间隔天数 > 0 判定 backwardation，月度调仓（月末收盘出信号、次日收盘成交），处于 backwardation 的品种做多主力、否则持现金，品种等权，锁死单边 3bp，2016-2026 对「同品种全体月份始终持主力」的静态基准净年化增量 > 0 且 NW t >= 2，且对随机同长度状态时移对照分位 >= 95%——商品时序 carry 择时（H0087 横截面 carry FAIL 的另一半，多市场 commodity×carry 时序从未测过）

## 1. 假设（一句话，可证伪）
> 在中国商品期货主力连续（SHFE/CZCE/DCE/GFEX，2016-2026，59 个品种）上，做时序期限结构 carry 择时：
> 每品种用近月对次近月年化贴水 (F_near/F_far−1)×365/间隔天数 > 0 判定 backwardation，
> 月度调仓（月末收盘出信号、次日收盘成交），back 品种做多主力、否则持现金，品种等权，锁死单边 3bp，
> 相对「流动性池全体月份始终持主力」的静态基准净年化增量 > 0 且 NW t ≥ 2，
> 且随机状态时移对照分位 ≥ 95%。

## 5. 口径锁死（写完不许再改）
- 策略角色（alpha / diversifier / hedge / execution）：alpha（时序择时）。
- 宇宙 / 可投池规则：20 日均主力成交额 ≥ 1 亿元（10000 万元）；收盘价、到期月 > T−45 日。
- 成本（单边 bp，含税费滑点）：单边 3bp，只在状态翻转时计（事件驱动换手）。
- 调仓频率与持仓数：月度（月末收盘信号、次日收盘成交）；back 品种等权。
- 基准（同池等权 + 指数对照）：流动性池全体月份始终持主力，等权。
- 目标函数与判读线：增量 > 0 且 NW t ≥ 2，置换分位 ≥ 95%，前后两段同号。
- 信息→决策→成交→PnL：月末收盘近/次近月收盘价 → 次日收盘成交 → 持有一月。
- 压力成本与容量假设：单边压力 6bp。
- 尝试账本：共 1 项——主口径（carry > 0 做多、否则现金）。

## 9. 留给后人的一句话
**商品的贴水状态对品种时序收益没有筛选能力。** 用 carry > 0 裁决持仓，99.3% 的交易日都在场内，
等于一个几乎不动的静态组合；相对「始终持有」只多赚 1.7 个百分点、检验不显著、随机时移只排 86 百分位，
后半段还转为负。前半段的 3.9 个百分点正差不足以支撑机理。

在月度频率上不存在可提取的 alpha，carry 家族（H0057/H0095/H0292/H0087/H0304）至此全面关闭。**
