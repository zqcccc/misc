# H0108 · 在 A 股可转债全宇宙上，『低价 ∩ 低转股溢价率』（双低）组合相对 H0076『仅低价』主口径有正的净 alpha 增量（NW t≥2）——即叠加低溢价率第二层筛选能在低价券里剔除『高溢价=正股深度虚值的价值陷阱』，从而提升风险调整后收益

## 1. 假设（一句话，可证伪）
> 在 A 股可转债全宇宙（2018-01-01~2026-09，含退市/违约，与 H0076 同一宇宙与成交口径）上，
> **『低价 ∩ 低转股溢价率』（双低）组合相对 H0076『仅低价』主口径有正的净 alpha 增量（NW t≥2）**；
> 反向命题（方向性判别）：『低价 ∩ 高溢价率』应显著弱于『仅低价』，即叠加低溢价率筛选
> 能在低价券里剔除「高溢价 = 正股深度虚值 = 高信用/期权价值陷阱」的券，从而提升风险调整后收益。

## 2. 机理（为什么应该成立）
**这是对 H0076 唯一 PASS 的「低价 value」边的内部提纯，机理与 H0076 同源但多一层：**

1. H0076 已证明「低价」本身有 alpha（8 年半 +5.74%/年，来自债底保护 + 下修/正股上涨的免费期权）。
2. 但「低价」是一个**粗粒度信号**：低价券内部横跨了两种完全不同的券——
   - **低溢价率低价券**：转股价值相对高（正股没跌透），价格贴近转股价值，下行有债底、上行保留真实弹性 → 是「便宜且期权还值钱」的好券；
   - **高溢价率低价券**：正股已深度暴跌、转股价值极低，价格远超转股价值（深度虚值），期权是远虚值彩票、下行还要吃信用/退市风险 → 是「便宜但便宜得有道理」的价值陷阱（fallen angel）。
3. 若低溢价率筛选能把后者剔除，就应在 H0076 的「低价」基础上**再提纯出更高夏普的券**，且这层增量
   在 2024 年（首例实质违约、信用重定价）之后应当更明显——因为那正是高溢价 fallen angel 被集中出清的年份。
4. **谁付钱/为什么难套利**：与 H0076 完全一致（机构评级门槛 + 散户彩票偏好 + 单券容量小、逐券信用研究人力密集），
   只是把「信用研究」用「低溢价率」这一廉价代理量做了部分替代。

**本卡预先承认的最可能死法（自我证伪线）**：低溢价率在横截面上与「高正股弹性/高 β」高度正相关
（溢价率低 ⟺ 转股价值高 ⟺ 股性足）。所以「双低」可能只是把 H0076 的防御型曲线往「偏股/偏 β」方向拉——
**在涨的年份多赚（2019/2020/2025）、在跌的年份多亏（2018/2022/2023/2024）**，净增量的正负取决于
「剔除价值陷阱的收益」与「引入更多正股 β 的代价」谁大。若后者占优，双低增量 ≤0 甚至为负。

## 3. 先验检索（动手前必做，写结论不写过程）
- **正面（双低有效派）**：中信证券长期回测（2019-01~2025-05）双低策略年化 13.63%、夏普 1.21、MDD 12.33%
  （GitHub 散户手册转引）；国信《转债策略精研(三)》：双低 2019-2021 超额 7.72%、2022-2024M2 超额 6.13%，
  且「双低在盈利领跑的同时风控向低价靠拢」。
- **负面（充分，且是本卡先验核心）**：
  1. **中信双低 13.63% ≈ H0076 仅低价 12.63%**——两条口径的绝对收益几乎重合，暗示低溢价率这层**几乎没有增量**。
  2. **民生证券 2024 转债风格指数**：2024 全年 双低 4.76%（超额 −1.50%）**跑输 低价 5.32%**；
     低溢价 16.14% 反而第一（靠 9·24 政策牛的权益弹性）。**在信用压力年，双低没有赢过低价。**
  3. **信达《不一样的转债多因子》(2024-08)**：经典双低「近年来多头、多空效果都有所削弱」「双低多头组**始终偏股**的特性，
     导致市场前期高估了权益牛市下的双低策略效果」——即双低的历史优势可能是权益牛市 artifact。
  4. **华安转债周记(2024-08-11)**：双低 2024 年两轮大幅回撤后累积收益转负、超额胜率从 83% 降到 57%。
- **与台账相邻性**：直接是 H0076（唯一 PASS 的 value 卡）的增强延伸，parent=H0076；与 H0106（转债隔夜/日内，已 FAIL）
  不同机理。台账此前 `qr search 转股溢价率` 零命中，本卡是**第一次把转股溢价率作为独立信号**纳入。
- **先验预测（写在动手前）**：**FAIL**——低溢价率增量 ≈ 0 甚至略负，理由 = 上面三条负面证据 + 机理层的 β 污染。

## 4. 数据需求
- 资产：A 股全部可转债，宇宙与成交时序完全复用 H0076（`cn_convertible/data/panel_close/open/volume.parquet`，
  4655 日 × 1014 券，含退市/违约券的完整历史）。
- **新增字段**：历史转股价值 / 转股溢价率。数据源 `akshare.bond_zh_cov_value_analysis(symbol=6位码)`，
  返回日频 `日期/收盘价/纯债价值/转股价值/纯债溢价率/转股溢价率`。
- **PIT 依据**：该接口的「转股价值」序列在【下修】日单日跳升（下修=转股价下调 → 转股价值=正股价/转股价×100 跳升），
  说明它用的是**历史时变转股价**，而非用当前转股价回看历史（那会抹平跳升、造成未来函数）。
  这正是 H0076 §4 因「转股价历史无法 PIT 取得」而放弃双低口径的**解法**。
  ⚠️ 残留风险（必须诚实记录）：若数据源把「未来下修」回填到更早日期，会让过去券的溢价率**偏低**、
  造成「偏向选到后来下修的券」的轻度前视。缓解：① 下修只影响少数券、少数日期，对横截面排序影响有限；
  ② B 层用「剔除转股价值单日跳升（下修事件）前 60 天窗口」重跑做 PIT 敏感性。
- 起止：2018-01-01~2026-09-04（与 H0076 一致）。

## 5. 口径锁死（写完不许再改）
- 策略角色：**alpha**（纯多横截面选券，与 H0076 仅低价主口径比增量）。
- 宇宙 / 可投池规则：**与 H0076 §5 逐字一致**（在市券、上市次日起可买、退市按最后可得收盘价平仓、
  停牌不进池、不按价格档位额外剔除、2018-01-01 起）。
  **唯一新增规则**：双低/溢价率口径下，t 日「转股价值缺失」的券**不参与溢价率排序**（无法定溢价率），
  其被排除的比例单独报告（blocked_premium_frac），**不进该期持仓但计入宇宙数**。
- 成本：**5.0bp 单边**（Σ|Δw| 逐日累加，含买卖双边），压力档 ×2 = 10.0bp。与 H0076 完全一致。
- 调仓与持仓数：**20 交易日调仓**；双低 = 先按 t 收盘价升序取最低 **40%** 分位（宽池），
  再在宽池内按转股溢价率升序取最低 **50%**（净 20%），等权；min_n=5、在市 <25 不建仓（与 H0076 同）。
  净持仓 20% 与 H0076 对齐，保证增量比较不是「持仓数不同」造成的。
- 基准：同期全转债等权池（与 H0076 同）；**主比较对象 = H0076 V0 仅低价 20% 的资金曲线**（增量检验）。
- 目标函数与判读线（现在写死）：
  - **主判读线 L1**：双低 对 仅低价 的净 alpha 增量 > 0 且 NW t≥2（增量回归，双低收益 − 仅低价收益 作因变量，
    HAC/NW；或对同池等权回归截距之差）。
  - **L2 绝对有效性**：双低 对同池等权 净 alpha > 0 且 NW t≥2（保证它不是「两个都差，只是双低稍好」）。
  - **L3 方向性**：低价∩高溢价（反向）对仅低价的净增量 < 0（剔除高溢价确实有害）。
  - **尾部**：双低 最大回撤 ≤35%、单日亏损 ≤5%（沿用 H0076 预注册线）。
  - **稳定性**：post-2024 子样本双低增量同号；逐年剔除增量不靠单年；溢价率梯度（低价 40% 池内按溢价率
    分 4 档）alpha 单调。
  - DSR ≥0.90、置换分位 ≥95%（若置换适用，主统计量=对仅低价的增量）。
- 信息→决策→成交→PnL：与 H0076 一致（t 收盘信息 → t 收盘后决策 → t+1 开盘成交 → PnL 到 t+21 开盘）。
- 压力成本与容量假设：10bp 压力；单券 500 万、组合 1 亿封顶（低价券流动性差，沿用 H0076）。
- 尝试账本（全部计入 trials）：
  - V0 = 双低主口径（40% ∩ 50% = 20% 持仓，5bp）——**唯一进入裁决的规格**；
  - V1 = 低价 40% ∩ 高溢价 50%（反向对照）、V2 = 仅低溢价率最低 20%（不筛价格，纯溢价率）、
    V3 = 仅高溢价率最高 20%、V4 = 经典双低值（价格 + 溢价率×100，升序取最低 20%）、
    V5 = 10bp 压力成本、V6 = 低价 50% ∩ 低溢价 40%（宽度 30%/50% 敏感）。
  - 全部 trials 落 `cn_convertible/out/h0108/trials.csv`，DSR 用它算。

## 8. 裁决

**FAIL**，死因 = **信号无增量**。

低溢价率这层筛选**没有给「仅低价」带来净 alpha 增量**：双低相对仅低价的年化差 +1.14%（t=1.03），
控制 β 后塌到 +0.22%（t=0.18），等于零。增量几乎全部来自 β——双低只是把 H0076 的防御曲线
往「偏股」方向拉了 7.7% 敞口（β 0.593→0.743），所以波动从 9.47% 升到 10.92%、回撤从 −14.77% 深到 −16.17%，
alpha 反而从 +5.74% 掉到 +5.31%。**这不是提纯，是换皮（拿更多正股弹性，换掉一点防御 alpha）。**

三条判读线的证据链是自洽的：低溢价端增量不显著（L1 FAIL），高溢价端显著为负（L3 过），
溢价率四分位是一条 β 单调的缓坡而非尖锐信号（梯度过）——合起来就是一句：**溢价率是 β 的代理，不是独立的 alpha 维度。**
这恰好落在 §2 预注册的「最可能死法」（低溢价 ⟺ 高转股价值 ⟺ 高正股弹性 ⟺ 高 β）上，也印证信达
「双低多头组始终偏股」的判断，以及民生 2024 年「双低 4.76% 跑输低价 5.32%」的样本外表现。

**残留风险（不影响结论方向）**：转股价值序列若存在「未来下修回填」的轻度前视，会让过去券的溢价率偏低、
偏向选到后来下修的券——这只会**抬高**双低的账面增量；实测增量都已 ≈0，去掉这个偏向后只会更小/更负，
所以 FAIL 结论对前视是稳健的。未做独立转股价交叉核验（成本收益不划算，结论已决定性）。

**一张卡顺带回答的相邻问题**：经典「双低值」（价格+溢价率×100，dual_score）alpha +5.85%（t=2.83）≈ 仅低价 +5.74%，
β 却从 0.593 冲到 0.940——所以**经典双低值同样只是 β 换皮，没有 alpha 增量**。纯低溢价 20%（prem_only）
更是纯 β 组合（β 1.435、alpha +2.00% t=0.68 不显著）。三种「双低」口径结论一致。

## 9. 留给后人的一句话

**「低价」和「低溢价率」在可转债里不是两个独立维度，是一个维度——它们都映射到「多少正股弹性（β）」：**
低价 ≈ 低 β（防御），低溢价 ≈ 高 β（进攻），两者在横截面上近似负相关。所以「双低」这个被散户和卖方
当作经典打底策略的东西，本质是「在低价里再挑股性足的那一半」，做出来的东西只是把 H0076 的防御曲线
加了一档杠杆 β——涨市多赚、跌市多亏，风险调整后（alpha）不仅没变好，还略变差。
想要 H0076 那条边的 alpha 更纯，方向不是往「低溢价」走（那是加 β），而是往「信用质量/回售条款/到期期限」
这些**真正独立的债性维度**走——但那需要逐券信用研究，正是 H0076 §8 黄旗里说的那条更难走、也更有壁垒的路。

三条可直接复用的结论：
- 溢价率信号**只在高端有效**：低价∩高溢价（fallen angel）确实显著更差（−3.01%/年 t=−2.36），
  所以「剔高溢价」有价值，「选低溢价」无增量——这是一个**非对称**信号，不是对称的排序因子。
- 台账第一次把 `bond_zh_cov_value_analysis` 的转股价值/溢价率历史纳入 PIT 回测（953 只、0 缺失、
  1564 次下修跳升），这条路数据层面已通，后人做「高溢价剔除」「双低陷阱」相关假设可直接复用
  `cn_convertible/data/panel_conv_value.parquet` + `panel_premium.parquet`。
- H0076 的低价 value 边**扛住了增强攻击**：它已经是这个维度上接近最优的构造，再往上叠价格/溢价率的
  线性组合都只是在调 β，不是调 alpha。
