# H0133 · 在中金所股指期货（IF/IH/IC/IM 逐张合约官方日线 2010-2026，非连续合约）上，对冲需求集中在近月导致【年化贴水随到期期限变浅】：因此对一个本来就要拿 A 股宽基敞口的人，【逐月滚动当月合约】相对【买入隔季合约持有至到期再转下一张隔季】在锁死单边 1.0bp（隔季压力档 3.0bp）下有正的净年化差且 NW t>=2；判读线 L2 换手与在市节奏匹配的『随机选哪张合约持有』置换分位>=95%，L3 成本×2 后仍>0，L4 两子段同号并按 B0018 报 MDE，L5 机理判别：收益差必须能被分解为『入场时年化基差之差』且同号同量级——若年化基差之差很小而总差大，则说明赚的是换手节省或价格路径而非贴水期限结构，判无机理。若方向显著为负则判方向反了

## 1. 假设（一句话，可证伪）
> 在中金所股指期货（IF/IH/IC/IM **逐张合约**官方日线，非连续合约）上，对冲需求集中在近月，
> 使**年化贴水随到期期限变浅**；因此对一个本来就要拿 A 股宽基敞口的人，**逐月滚动当月合约**
> 相对**买入隔季合约持有至到期再转下一张隔季**，在锁死单边 1.0bp 下有**正**的净年化差且 NW t≥2；
> 且这个差必须能被分解为"入场时年化基差之差"——若年化基差之差很小而总差大，则判无机理；
> 若方向显著为负，则判方向反了。

## 2. 机理（为什么应该成立）
**制度约束 + 风险溢价转移**（不是行为偏差，也不是价格预测）。

1. **贴水是入场时锁定的确定性收益**：中金所股指期货现金交割，交割结算价 = 到期日现货指数最后
   2 小时算术均价。买入时的基差（期货 − 现货）在到期时强制归零 → **贴水就是多头持有到期的收益**。
   所以两条路径的收益差 ≈ 各自入场时的年化基差之差 − 换手成本差，**不依赖对未来价格的任何预测**。
2. **对冲需求集中在近月**：市场中性 / 指数增强 / 场外雪球的空头腿、以及产业套保，都堆在
   当月与下月（流动性最好、按月滚动）。空头过剩 → 近月被压得更低 → **年化贴水更深**。
   ⇒ 想拿这份贴水的人应当滚近月。
3. **远月的劣势还有两条**：① 隔季合约流动性差得多（买卖价差宽、盘口薄），名义贴水的一部分会被
   实际成交吃掉；② 保证金占用期间无法减仓，失去灵活性。

**反向机理（必须诚实写，它同样说得通）**：
- 若对冲需求其实分布在整条曲线上（雪球对冲常用季月/远月锁长期敞口），年化贴水的期限结构可能
  是**倒挂**的（远月更深）→ 远路径反而更优 → 那就是"方向反了"。
- 若期限结构**平坦**，则两条路径的差别只剩换手成本，年化差会在 ±20bp 量级 → 大概率测不出来。

**先验**：我给**中性偏高**（不是"相信"，是"这个效应的确定性高于普通 alpha，因为它是制度性价差
而不是预测"）。但相邻两张卡（H0050 基差择时、H0057 跨期价差回归）都 FAIL，说明在这个邻域
"从基差里榨**额外**收益"很难——不过它们榨的是**择时 / 回归**，本卡榨的是**恒定路径的期限选择**，
机理不同。

## 5. 口径锁死（写完不许再改）
- **策略角色**：`alpha`（载体选择；两条路径都是**纯多头**、名义敞口 100%）。
- **合约识别**：每个交易日，把该品种当日在市的合约按到期月份排序，取
  **C0 = 最近到期（当月）**、**C3 = 最远到期（隔季）**。中金所同时挂 4 张：当月 / 下月 / 下季 / 隔季。
  只用当日 `open_interest > 0` 且 `close > 0` 的合约。
- **路径 A（近）**：持有 C0；C0 到期后换到新的 C0。
  **路径 B（远）**：持有 C3；C3 到期后换到新的 C3。
- **换仓时序（锁死，满足 information ≤ decision ≤ execution ≤ pnl_start）**：
  - `information` = 持仓合约最后交易日前第 3 个交易日收盘（此时已确知哪张是 C0/C3、何时到期）
  - `decision` = 同日收盘后（规则是机械的，不依赖任何待估数据）
  - `execution` = 最后交易日前第 **2** 个交易日**收盘**（旧合约卖出、新合约买入，同刻）
  - `pnl_start` = 执行日收盘
  - 换仓提前 2 天而非在最后交易日，是为了避免"最后交易日流动性枯竭"的乐观假设。
- **收益记账**：同一合约内 `close_t / close_{t-1} − 1`；换仓当天**不跨合约算价差跳变**
  （卖旧、买新各自按当日收盘价，成本双边计）。这是 H0057 的坑。
- **成本**：单边 **1.0bp**（与 H0047 一致）。压力档：**路径 B（隔季）3.0bp、路径 A 2.0bp**——
  这是事前锁死的、对**路径 B 不利**的设定（因为远月流动性差）。主口径两条路径都用 1.0bp。
- **主口径**：**IF/IH/IC 三品种等权合并**，样本 **2016-01-04 ~ 2026-09-04**（避开 2015 股灾后
  贴水/升水剧烈翻转的那段；**事前锁死，不是事后挑区间**）。**IM（2022-07 起）单独附报**，
  不进主口径。
- **基准**：两条路径**互为对照**。ETF（510300/510500/510050）只作 sanity check，不参与判读。
- **判读线（事前锁死，任一不过即 FAIL）**：
  - **L0 成本闸**：（毛差 / 换手成本差）≥ 2，否则判 `成本吃穿`。
  - **L1 主**：路径A − 路径B 的净年化差 **> 0 且 NW t ≥ 2**（方向预测：近月更好）。
    **若显著为负 → 判 `方向反了`**。
  - **L2**：换手与在市节奏匹配的【随机选哪张合约持有】置换分位 **≥ 95%**。
  - **L3**：压力成本档（B=3.0bp，A=2.0bp）后净年化差仍 **> 0**。
  - **L4**：2016-2019 / 2020-2026 两个子段**同号**，并按 B0018 报各段 **MDE**。
  - **L5 机理判别**：把总差分解为 (a) **入场时年化基差之差**、(b) 换手成本差。
    要求 (a) 与总差**同号且 |a| ≥ 0.5 × |总差|**。若 (a) 很小而总差大 → 说明赚的是换手节省或
    价格路径而非贴水期限结构 → 判 `无机理`。
  - **附报（不参与判读）**：C0/C1/C2/C3 四条期限各自"持有到期"的年化收益与年化基差，
    连成一张期限结构表。
- **尝试账本**：**只有 1 个主规格**（近 vs 远）。四条期限的各自表现是**描述性期限结构表**，
  不是可挑选的变体。DSR 按 n_trials = 1（等价 PSR）计。区间 / 过滤器 / 成本一律不得事后改。

## 8. 裁决
**FAIL —— 死因：强度不足。**

五道 C 层线全倒：净差 +0.154%/年、NW t = 0.213、置换 42.1 分位、PSR 0.580、分块自助 P5 0.884、压力档翻负（−0.051%）。
两个子段同号（+0.256% / +0.090%）但 MDE 分别是 4.17% 和 1.98%——按 B0018 只能写"**测不出来**"，不能写"效应消失了"。

**关于 §5 预注册的 L0 死因映射**：L0 写的是"（毛差 / 换手成本差）≥ 2，否则判 `成本吃穿`"。实测 0.363 / 0.256 = **1.42 < 2**，L0 确实没过。
但我**不采用** `成本吃穿`，理由必须写明：那个标签暗示"效应是真的，只是被手续费吃掉"——**不是**。即便把成本设为零，毛差也只有 0.363%/年、t = 0.50、MDE 2.03%，**免费交易也测不出这个效应**。所以取更诚实的 `强度不足`。（这是我本轮第二次偏离预注册的死因映射，两次都是同一个原因：预注册的映射描述的是"被成本吃掉"，而实际情况是"本来就没东西可吃"。）

**L5 的真正发现（比主判读更有价值）**：名义年化基差的期限结构**方向是对的**——近月贴水确实比隔季深得多（IF 7.19% vs 4.55%，IC 13.26% vs 10.17%），
按它推算近月每年该多赚 2.5 个点；**但实际只多赚 0.36 个点（不到预测的 1/6）**。原因是**基差期限结构会随时间平移**：
你今天买的隔季合约，越接近到期，它自己的年化贴水就越深，最后追上了近月的水平。已实现 carry 的实测值（IF 4.94% vs 4.32%、IC 10.49% vs 10.51%）
证明了这一点。**结论：不能用"当前的年化基差"去推算"持有到期能拿多少 carry"——那是把一条会平移的曲线当成了固定斜率。**

## 9. 留给后人的一句话
**中国股指期货的贴水，用当月合约每月滚、还是用半年后到期的远月合约拿着不动，赚的钱一样多。** 十年下来两条路一年只差 0.15 个百分点，
而每月滚动多付的手续费（一年 0.26 个点）几乎把这点优势全吃掉，手续费再翻一倍就变成倒贴。
看起来"近月贴水更深、应该更划算"是个好理由，但远月合约越接近到期，它自己的贴水会一路变深、最后追平——
名义上的期限结构骗人，实际拿到手的 carry 两条路几乎相同（IF 4.9% vs 4.3%，IC 10.5% vs 10.5%）。

三条可复用的东西：
1. **对实务：H0047 那每年 5.7 个点的便宜，不需要靠每月滚动去拿。** 换成隔季合约、一年只换两次手，carry 基本照拿，换手降到六分之一。
   这不是"新 alpha"，是"少折腾还不吃亏"——但前提是隔季那 150 亿/日的成交量对你够用。
2. **对方法：别用"当前年化基差"外推未来的 carry。** 期货的基差期限结构会随合约到期平移，今天的远月基差不是你持有它能拿到的东西。
   要测 carry 就直接测「路径毛收益 − 同期指数收益」，别用瞬时基差做代理。
3. **对这个家族：台账 3 个 PASS（H0047/H0076/H0121）都是"换载体拿制度性价差"，而"在同一载体内部换期限"这一层现在也测过了——答案是"没得挑"。**
   制度性价差的便宜在**跨资产类别**那一层，不在期限那一层。
