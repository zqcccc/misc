# H0117 · 在中国商品期货（SHFE/CZCE/GFEX 逐张合约，2016-2026）上，个人客户不得持仓进入交割月的规则造成的被迫平仓，使近月合约在交割月前最后 5 个交易日相对同品种次月合约系统性走弱；在交割月前第 5 个交易日收盘建仓『空近月/多次月』等名义跨期价差、交割月前 1 个交易日收盘平仓，锁死单边 4bp 成本后 2016-2026 日频资金曲线净年化>0 且 NW t>=2，且对随机平移窗口置换分位>=95%

## 1. 假设（一句话，可证伪）
> 在中国商品期货（SHFE/CZCE/GFEX 逐张合约，2016-2026，DCE 数据不可得已声明）上，
> 「自然人客户不得持仓进入交割月」这条**交易规则**会在自然人清零截止日 D 之前形成可预期的被迫平仓流，
> 使近月合约在 [D−5, D] 窗口相对同品种次活跃合约系统性**走弱**；
> 于 D−5 收盘建仓「空近月 / 多次月」等名义跨期价差、D 收盘平仓，
> 在锁死单边 4bp（含费+滑点）成本后日频资金曲线净年化 > 0 且 NW t ≥ 2。

## 2. 机理（为什么应该成立）
**制度约束 + 被迫交易（forced liquidation）**，不是数据挖掘。

- 自然人客户不能参与实物交割（不能开增值税发票），因此交易所规则强制其在特定日期前把交割月合约
  持仓清零，逾期由交易所**强行平仓、盈利没收、亏损自担**（《上期所交割细则》第四条、《郑商所期货交割细则》
  第六条、《大商所交割细则》第四条；2026 年各期货公司执行口径一致）。
- 截止日 D 是**日历上可预知的**（不是事件公告），且**不管盈亏都必须交易**——这就是典型的被迫交易：
  它不需要任何预测能力，只需要在正确的一侧站着。
- **谁付钱**：被迫平仓的自然人。他们在 D 之前必须卖出（若为净多）或买回（若为净空），
  愿意为此接受比平日更差的价格。**承接方（法人户/做市商）赚的是流动性补偿，不是方向判断。**
- **方向先验**：中国商品期货的自然人以多头投机为主（散户做空门槛与心理成本更高），
  故假设被迫平仓以卖出为主 → 近月在窗口内相对次月走弱 → 空近月/多次月为正。
  **这个方向是本卡要被证伪的对象之一**（若方向反了、且反向也不足以覆盖成本，同样判 FAIL）。
- **天然的对照组（机理判别）**：三所规则强度不同——
  - CZCE/GFEX：**硬约束**，自然人完全不得进入交割月，须在交割月前一月倒数第 2 个交易日收盘前清零。
  - SHFE/INE（除 FU/SC/LU）：**软约束**，自然人可持整数倍进入交割月，只在最后交易日前第 5 个交易日清零。
  若效应真由强制平仓驱动，**硬约束组的效应应当显著强于软约束组**。这是一条独立的方向性机制检验。

## 3. 先验检索（动手前必做，写结论不写过程）
- **没有找到任何公开的实证/学术研究**量化「中国商品期货交割月自然人强平」的价格效应。
  检索到的全部是券商/期货公司的**风险教育内容**（搜狐、和讯、头条，2026-07~09），
  内容高度雷同且为 SEO 稿，无一家给出效应量。**既没有正面证据，也没有人反驳**——
  这是"没人公开做过"，不是"没人做过"，不能当成发现了便宜。
- **检索到的负面证据（关键）**：上述风险提示**一致地**强调同一点——
  「近月合约流动性逐渐向远月转移，成交量与持仓量萎缩，买卖价差扩大、滑点成本增加」
  「越是临近自然人退出时间节点，合约流动性可能越差」「保证金比例阶梯式上调」。
  **这直接把本卡的最高风险指向「不可成交」而不是「方向错」。**
  因此 A 层必须先量近月合约在窗口内的成交量/持仓量分布，流动性不足就直接判不可成交，不许靠调参数绕过。
- 台账相邻 ID 与区别：
  - H0055（IC/IM 股指期货交割周贴水收敛，FAIL 强度不足）：中金所**现金交割**，自然人可持有到交割日，
    不存在"禁止进入交割月"这条约束；标的是股指。本卡是商品期货 + 自然人禁令。
  - H0057（IC/IM 跨期价差，FAIL 强度不足）：同样是金融期货，且它自己警告了"换月价差跳变=伪收益"。
  - H0087（中国商品 carry 横截面排序，FAIL 信号无增量）：**月度再平衡、横截面排序**；
    本卡是**逐合约交割窗口的时序事件 + 跨期价差**，判读量与构造都不同（carry 是"谁更贵"，
    本卡是"同一对合约在自己生命周期末端的异常漂移"）。
  - H0107（中国商品 TSMOM，FAIL 信号无增量）：时序动量，与本卡无关。
  - H0084（A股/期货隔夜日内）：不同市场不同口径。
  - 与 H0047/H0076 同属"结构性/制度摩擦"族——这正是台账唯一两条绿线所在的族。

## 4. 数据需求
- 资产：**逐张合约**（不是连续合约）官方日线，SHFE / CZCE / GFEX（年鉴 §3：`akshare.get_futures_daily`）。
  **DCE 本机取不到（年鉴 §3 已知缺口，akshare 与直连均 JSONDecodeError），本卡宇宙缺大商所
  全部品种（豆粕/铁矿/棕榈油/玉米等）——结论必须声明这个缺口，不许说"中国商品全市场"。**
- 字段：`symbol, date, open, high, low, close, volume, open_interest, turnover, settle, variety`。
  `turnover` 单位万元（年鉴已核对），用于反推每手名义金额（`turnover*1e4/volume`）做腿数配平。
- 颗粒度：日线；区间 2016-01-04 ~ 数据末（2026-08/09）。
- 现有资产：`cn_commodity/data/raw/SHFE_all.parquet`、`data/raw/CZCE_*.parquet`、
  `data/raw/GFEX_*.parquet`、`data/mon/SHFE_*.parquet` 可直接支撑，**无需新抓数**。
- 到期月解析：SHFE/GFEX = `品种+YYMM`（4 位）；**CZCE = `品种+YMM`（3 位，十年一循环，
  必须结合交易日解析）**——年鉴 §3 已警告写死 `2000+Y` 会错十年。

## 5. 口径锁死（写完不许再改）
- 策略角色：**alpha**（零成本跨期价差，与方向性 beta 无关）。
- 宇宙 / 可投池规则：
  1. 事件单元 = (品种, 合约) 的一个自然人清零截止日 D。
  2. **D 的定义（按交易所，事前可由公开合约条款与交易所细则得知）**
     - CZCE / GFEX（硬约束）：D = **到期月前一月的倒数第 2 个交易日**（期货公司执行口径，
       自然人须在此收盘前清零；来源见 §3 各期货公司 2026 年 7/8 月通知）。
     - SHFE / INE（软约束，除 FU/SC/LU）：D = **该合约最后交易日前第 5 个交易日**
       （《上期所交割细则》第四条：最后交易日前第三个交易日收盘后持仓应为 0，
        期货公司执行口径提前到最后交易日前第 5 个交易日）。
       FU / SC / LU：同样取最后交易日前第 5 个交易日（SC 实为前第 8，统一取第 5 以保持单一口径）。
     - 最后交易日 = 该合约在数据中的最后一个报价日（交易所合约条款事先公布，非事后构造）。
  3. **窗口**：建仓 D−5 收盘，平仓 D 收盘，持有 5 个交易日（K=5 为主口径；K=3/10 为鲁棒档，只报不改裁决）。
  4. **近月腿 N** = 该合约本身。**次月腿 F** = 同品种中到期月严格大于 N 的到期月、且在 [D−5, D]
     每个交易日均有成交（volume>0）的合约里，**窗口起点前 5 个交易日日均成交额最大**者
     （年鉴 §5 坑 2：不能用日历上的"次月"，中国商品流动性只集中在少数月份）。
  5. **可投池过滤（a priori，非按结果调）**：
     - N 与 F 在 [D−5, D] 的**每一个**交易日 volume > 0（否则不可成交，剔除并计入 blocked_frac）；
     - N 在 D−5 的 open_interest ≥ 3000 手；
     - N 与 F 在窗口起点前 5 日日均名义成交额（turnover，万元）≥ 500 万元。
  6. 腿数配平：按每手名义金额 `unit = turnover*1e4/volume` 把两腿配成等名义。
- 成本（单边 bp，含税费滑点）：**4.0bp/腿**（年鉴锁死值 3.0bp 是月度调仓口径；本卡是交割前低流动性合约，
  上调 1bp）。每个事件开 2 腿 + 平 2 腿 = **4 × 单边 = 16bp/事件**。压力档 ×2 = 32bp/事件。
- 调仓频率与持仓数：每事件 5 个交易日；事件数 = 品种数 × 12/年（过滤后以实测为准）。
- 基准（同池等权 + 指数对照）：
  - **主基准 = 0**（零成本价差，看绝对收益；PROMPT §3.3 多空口径）。
  - **平移对照**：同一对合约在 [D−30, D−25] 的同长度窗口（非交割窗口）的同样价差收益。
  - **Beta 对照**：把日收益对同池主力等权多头日收益回归，报 CAPM alpha 与 β。
- 目标函数与判读线（**主判读线只有一条，其余是稳健性与机理线**）：
  1. **主判读线**：净年化 > 0 且 NW t ≥ 2（日频资金曲线，Newey-West lag = 21）。
  2. 成本压力档 ×2 后净年化仍 > 0。
  3. 随机平移窗口置换分位 ≥ 95%（保持窗口长度与在市结构，只平移窗口起点）。
  4. 两子段（2016-2020 / 2021-2026）同号；并按 B0018 报各子段 MDE（MDE 必须 < 全段效应量，
     否则"子段不显著"不能解释成"效应消失"）。
  5. **机理线（不是主判读线）**：CZCE/GFEX 硬约束组净收益 > SHFE/INE 软约束组净收益。
  6. **可成交线**：因窗口内无成交而被剔除的事件占比（blocked_frac）≤ 5%，否则结论作废。
- 信息→决策→成交→PnL：
  - information_time = D−5 日盘中（D 由交易所规则与合约条款事前确定，D−5 在交易日开始前即可算出）
  - decision_time = D−5 日 14:57 前
  - execution_time = D−5 日**收盘集合竞价**（成交价 = 当日 close）
  - pnl_start = D−5 收盘；pnl_end = D 收盘（同样以收盘集合竞价成交价计价）
  - 两腿同一时点成交；逐日收益 `r_t = ret_F,t − ret_N,t`（同一合约 `close_t/close_{t−1}−1`，
    不跨合约，规避年鉴 §5 坑 1 的换月伪收益）。
- 压力成本与容量假设：成本 ×2；容量按"单事件单腿不超过该合约窗口内日均成交额的 1%"估算，
  只作数量级说明，不做精确容量模型。
- 尝试账本（参数/过滤器/区间/失败变体都计入 trials）：
  K ∈ {3, 5(主), 10}；交易所分组 {ALL, CZCE+GFEX, SHFE}；成本档 {1x, 2x}；
  腿定义 {次活跃(主), 日历次月}；价格口径 {close(主), settle}。
  **任何事后新增的变体都必须补记进本表并计入 DSR 的 trials。**

## 8. 裁决
**FAIL —— 成本吃穿**（并有 **不可成交** 作为第二条独立死因）。

1. **成本这一关**：毛边际 4.85bp/次，一次进出要付 16bp（两腿开+两腿平 × 单边 4bp），
   毛收益只有成本的 0.30 倍；12 个预登记变体（窗口 3/5/10 日、三个交易所分组、两种腿定义、
   结算价口径）的**净年化全是负的**，最好的一个也是 −2.25%/年。**没有一档能靠近过线。**
2. **能不能成交这一关**：4358 个候选事件里只有 1848 个两条腿全程都有成交，blocked_frac=57.6%，
   判读线是 ≤5%。近月合约在窗口内的成交量中位数只有 3783 手、最差的一成不到 578 手——
   **这正是检索阶段所有券商风险提示一致说的那句"越是临近自然人退出节点，流动性越差"。**
   这一条与成本无关，单独成立。
3. **不是"效应变弱了"，是"效应本来就这么小"**：硬约束组（郑商/广期所）毛边际 10.57bp/次、t=1.64，
   软约束组（上期所）−0.07bp/次——**规则越硬、近月被压得越狠，机理方向是对的**；
   但就算在最硬的那组、最有利的腿定义下（12.66bp/次、t=2.45），也只到成本的 0.79 倍。
   11 年里 5 年变号，不存在"某个稳定年份可以单独去做"。

**不许做的事**：不要再改窗口长度、不要再换腿定义、不要降低手续费假设——12 个变体已经把这个
参数空间走完了，最好的一档离过线还差一倍以上。也不要把"硬约束组 t=1.64"当成"效应存在、值得深挖"：
t=1.64 的毛边际配 16bp 的成本，期望值是负的。

**唯一还有一点价值的东西**：硬约束 vs 软约束的**方向差**（+10.6 vs −0.1 bp/次）说明
"强制平仓确实会压价"这件事在数据中看得见，只是量级太小。若将来能用**交易所的跨期套利指令**
（只对一条腿收费）把单次成本从 16bp 降到 8bp，硬约束组会变成 edge/cost≈1.3~1.6（THIN，仍不到 GO），
且需要品种有挂牌的日历价差合约。**这一条不构成本卡的重开理由，只作为后人评估时的算术参考。**

## 9. 留给后人的一句话
- **负面结论（主）**：中国商品期货"自然人不能进交割月"造成的强制平仓压力，**方向是真的、量级不够**——
  在最硬的规则下也就每次万分之十左右，而中国商品期货一次跨期进出的手续费就要万分之十六。
  **别再在"交割月/移仓/roll"这个族里找便宜了**：台账里 H0055（股指期货交割周）、H0057（股指跨期价差）、
  H0087（中国商品 carry 横截面）已经三面夹过，本卡从"制度性被迫平仓"这个最强的机理再打一次，
  结论一致——**这类效应在价格里是存在的，但都被成本和流动性先吃掉了。**
- **可复用的坑**：
  1. 逐合约日线的**到期月解析**：郑商所是 3 位 `YMM`（十年一循环），必须结合交易日反解年份，
     写死 `2000+Y` 会错十年（年鉴 §3 已警告，本卡已实现在 `prep.py::parse_expiry`）。
  2. **"有效最后交易日"必须用最后一个 volume>0 的日期**，不能用数据里最后一行的日期——
     很多远月合约很早就没有成交了，用后者会把 D 算到根本没人交易的时段。
  3. 券商/期货公司每年发布的"2609 合约自然人清零日通知"是**硬约束日期的可复现来源**，
     比直接读交易所细则好拿；上期所与郑商所规则强度不同，可以当天然对照组用。
- **数据资产**（后人可直接复用）：`cn_commodity/h0117/out/panel_contracts.parquet`
  （4561 张合约 / 58 品种 / 2016-01~2026-09，含到期月与每手名义金额）与
  `out/events_raw.parquet`（4358 个交割事件，含可成交状态标记）。
  **缺口：大商所全部品种取不到（年鉴 §3），本卡宇宙不是"中国商品全市场"。**
