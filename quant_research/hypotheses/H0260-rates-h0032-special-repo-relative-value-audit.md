# H0260 · 在利率市场美国国债拍卖事件（H0032线索）上，检验是否具备含特殊回购融资（Special Repo）的2Y/10Y现券逐笔可交易报价数据：核查本地及开源公开高频现券成交数据库（TRACE/BrokerTec/Treasury Direct拍卖明细），检验特殊回购费率与新老券（On-the-run vs Off-the-run）流动性价差能否支撑久期中性相对价值子卡构建，若数据不可得或缺失逐笔真实借券融资利率则客观裁决数据不可得（继承 H0032）

## 1. 假设（一句话，可证伪）
> 在利率市场美国国债拍卖事件（H0032 线索）上，检验是否具备含特殊回购融资（Special Repo）的 2Y/10Y 现券逐笔可交易报价数据：
> 核查本地及开源公开高频现券成交数据库（TRACE/BrokerTec/Treasury Direct 拍卖明细），检验特殊回购费率与新老券
> （On-the-run vs Off-the-run）流动性价差能否支撑久期中性相对价值子卡构建，若数据不可得或缺失逐笔真实借券融资利率则客观裁决数据不可得。

## 2. 机理（为什么应该成立）
**机理是国债新发券（On-the-run）特殊回购溢价与做市商库存回补假说（Specialness Premium & Inventory Absorption）。**

在美债拍卖事件中，一级交易商（Primary Dealers）在承销新券时需要借入老券（Off-the-run）对冲久期风险。由于新券流动性极佳，在回购市场上往往出现「特殊回购利率（Special Repo Rate）显著低于一般抵押回购利率（GC Rate）」的现象，持有新券出借可以获得丰厚的特殊回购利息补贴（Specialness）。理论上，利用新老券久期中性配对交易，并精准计入特殊回购融资收益，能够剥离单边市场涨跌，获得纯粹的流动性溢价套利回报。

## 3. 先验检索（动手前必做，写结论不写过程）
- **父卡证据**：H0032（拍卖后买入 TLT 裸多，FAIL，扣除市场贝塔后无超额，遗留复活线：获得含特殊回购融资的 2/10 年现券可交易报价后另立新卡）。
- **行业现实约束**：CUSIP 级别的国债逐日逐券特殊回购利率（Special Repo Rate）由 BrokerTec/DTCC/Tradeweb 等私有场外交易平台垄断，彭博（Bloomberg FIT/REPO）终端按高昂年费提供，公网和免费数据源（如 FRED/Yahoo Finance）完全不提供 CUSIP 级逐笔特殊回购借券利率。没有真实借券利率支撑的相对价值策略，任何回测都属于虚假拟合。
- **与相邻卡差异**：本卡作为 H0032 线索的正式接手核验，实事求是核查数据可得性。

## 4. 数据需求
需要：2016-2026 年美国 2Y/10Y 国债新老券 CUSIP 级别日频 Bid/Ask 真实可交易价格，以及逐日特殊回购利差（GC Rate - Special Rate）。
核实结果：本地仓内仅有 ETF（TLT/IEF/SHY）及官方拟合收益率曲线（`curve_daily.parquet`），完全缺失逐券 CUSIP 现券微观报价与回购费率；开源 API 无法免费获取。数据确凿不可得。

## 8. 裁决
`FAIL`（死因：数据不可得）
接手 H0032 遗留线索核实：
美债特殊回购费率（Special Repo Rate）与新老券（On/Off-the-run）高频逐笔可交易报价属于华尔街顶级投行及彭博专线私有高价值数据。公网与本地完全不具备相关数据源。在缺少借券融资成本数据的前提下，无法构建真实因果回测。依据实事求是原则，裁决 `FAIL`（数据不可得），关闭该复活线索。
