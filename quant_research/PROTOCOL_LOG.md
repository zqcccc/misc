# 协议版本台账

> 裁判（`quant-backtest-protocol`）**可以被修**，但每一版都要在这里留下记录。
> `qr protocol` 用它把当前指纹翻译成版本号，`qr rejudge` 用它算出哪些历史裁决需要重判。
>
> **只追加，不改写既有行。** 指纹是内容哈希，回答不了「这条裁决在新版下还成不成立」；
> 版本号加上「影响」才回答得了。这是「裁判不许动」被换掉的那条铁律的替代物。

## 影响取值

| 影响 | 含义 | 谁要重判 |
|---|---|---|
| `baseline` | 起始版本 | 无 |
| `none` | 只改文档、注释、重构，判读结果不可能变 | 无 |
| `tighten` | 门槛变严：原来能过的可能不再过 | 全部 `PASS` 卡 |
| `loosen` | 门槛变松：原来被拒的可能能过 | 全部 `FAIL` / `PARK` 卡 |
| `breaking` | 口径改变，方向不单一 | 全部已裁决卡 |

登记时选最保守的那一档。拿不准是 `tighten` 还是 `breaking`，就写 `breaking`。
