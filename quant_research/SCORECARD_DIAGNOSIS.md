# 打分卡诊断（2026-09-12）

> 目的：回答「这张七维打分卡有没有用」。结论先行：**当前证据既不能说它有用，也不能说它没用——
> 因为测量本身是坏的。在修好测量之前改维度或改权重，都是在对噪音做拟合。**

## 一、实测结果（n=99 张有分卡，129 张已裁决）

| 指标 | 值 | 判读 |
|---|---|---|
| 分数均值 / 标准差 | 80.2% / **10.7pt** | 几乎不分散 |
| 有效取值范围 | **[50%, 100%]** | 理论 [0,100%]，只用了 50% 带宽 |
| 最低分 | 7/14（仅 1 张） | **从没研究过低分候选** |
| AUC（分数 → 非FAIL） | **0.590** | 0.5 = 随机 |
| AUC 95% CI（Hanley-McNeil） | **[0.427, 0.753]** | 跨越 0.5，与随机不可区分 |
| 高分档 vs 中分档 Fisher 精确检验 | **p = 0.401** | 两档结局无显著差别 |
| 高分档 lift（相对 base 15.2%） | 1.26x | 15 个事件下的噪音 |
| 中分档 lift | **0.78x** | 比随机还差 |
| 统计功效（检出 AUC=0.65） | **0.07 ~ 0.12** | 比抛硬币好一点 |

**结论：n=99 时，即使真实 AUC=0.70，也有很大概率观测到 0.59。**
「测出无效」和「根本测不出」在当前样本量下是同一个观测。

## 二、三个结构性缺陷（按严重度排序）

### 缺陷 1：取值范围压缩 + 从不研究低分候选（最致命）

分数永远在 50%~100% 之间，且只研究 top-N。后果是**双向**的：

- 取值范围窄 → 分数与结局的相关性被数学地压低（range restriction / attenuation）
- 低分候选从未被研究 → **低分候选的结局永远不知道**。如果低分里其实藏着好东西，
  打分卡正在系统性地把它们排除掉，而这永远不会被发现

这构成一个自证循环：**只研究高分的 → 低分没有结局数据 → 无法证明低分其实也不错 → 继续只研究高分的。**

对照：47 张高分卡里 38 张 FAIL，其中「信号无增量」13 张、「方向反了」10 张——
这些失败**恰恰是机理维度（维度 1/2）本该拦住的**，说明高分里混着大量本该低分的候选。

### 缺陷 2：自评偏差（self-preference + central tendency）

提出想法的 agent 给自己的想法打分。已有实测文献：

- LLM 显著偏好自己生成的输出，机理是**给低 perplexity（自己更"顺"）的文本打高分**
  （arxiv 2410.21819）
- 前沿 LLM 家族在序数打分上**全部**表现出向中段压缩（低端高估、高端低估），
  且**改 prompt 和加 few-shot 都消不掉**（arxiv 2605.16386）
- agent 自评 gate 会退化成 accept-all：54 个周期 100% 自报改进，实测 56% 真实 delta ≤ 0
  （arxiv 2607.25152）

**这解释了为什么标准差只有 10.7pt。** 不是候选真的都差不多，是打分器在压缩。

### 缺陷 3：七维高度相关，实际有效维度只有 4~5 个

（rounds 里能解析到的 9 份七维明细表）

| 维度 | 与其余六维之和的相关 | 判读 |
|---|---|---|
| 1 机理强度 | **+0.67** | 严重重复测量 |
| 6 组合增量 | +0.47 | 中度 |
| 2 付钱者 | +0.38 | |
| 3 数据/时点 | +0.35 | |
| 4 成本余量 | +0.21 | 较独立 |
| 5 容量 | +0.21 | 较独立 |
| 7 证伪速度 | +0.09 | 最独立 |

+0.67 意味着「机理强」的候选在打分时会被顺带打高其他维度——
这是 rubric 里 **halo effect** 的标准信号（教育测评界的判据）。
七个维度里有两个（4 成本余量、7 证伪速度）相对独立，**它们才是真正携带增量信息的维度**。

## 三、实现层面的问题

1. **维度级分数没有落盘。** 七维只存在于 `rounds/*.md` 的 markdown 表格里，
   不进 frontmatter、`qr` 不解析。→ 永远做不了维度级归因、加权、AUC per dimension。
2. **`qr scorecard` 没有任何统计检验。** 只打印 3×3 计数表，无卡方/Fisher/AUC/Brier。
   判定「准不准」全靠人眼看数字（qr:719-773）。
3. **分档阈值是固定的 80%/55%。** 实际 90% 的卡落在 ≥80%，中分档和低分档几乎是空的。
4. **分母混用**：94 张 /14，5 张 /12（六维遗留）。`pct()` 按比例算所以没错算，但跨轮可比性受损。
5. **30 张已裁决卡没有 score 字段**，被静默过滤，样本白白少 23%。
6. **`screen_verdict`（GO/THIN/STOP，成本闸实测）是唯一客观的预测因子，`scorecard` 完全没读它。**
   实测：STOP 档非FAIL率 4.3% vs GO 档 15.4%——它比事前打分更有区分度。
7. **「必须留校准位」是纯口头要求**，代码零强制，实际只有 H0116 一张卡带 `calibration` tag。

## 四、业界的做法（调研结论）

### 有出处的

- **Man Group / AlphaGPT**：AI 生成的 idea 走**和人类提案同一套**评审流程，不是另一套 AI 打分。
  （man.com/insights/what-ai-can-do-for-alpha）
- **Man Group / AlphaTrend**：用**好/坏/不确定三分类基准测试**验证系统，
  核心指标是**能否把坏主意认出来**（淘汰率），不是选中率。（man.com/insights/alphatrend-agentic-research-workflows）
- **RD-Agent(Q)**（微软 NeurIPS 2025）：**没有选题打分卡**，用**多臂老虎机**按实际回测反馈
  分配研究预算。（arxiv 2505.15155）
- **WorldQuant BRAIN**：筛选用**硬阈值 + 相关性过滤**，不是多维加权打分。
- **Ilmanen《Expected Returns》**：评估收益溢价的标准（persistence / pervasiveness / robustness…）
  是学术界最接近选题打分卡的东西。

### 找不到的（不要包装成业界实践）

- AQR / Two Sigma / Bridgewater 的**内部选题 rubric 无公开一手文档**。
- 量化场景下**强制排名（forced ranking）**无公开证据（只有 HR 领域的 stack ranking）。

## 五、建议（按优先级）

### P0 · 先修测量，别修打分卡

1. **强制分散分数**：改为**本轮候选池内的分位数归一化**或强制排名，
   让每轮分数铺满 [0,100%]。不铺开取值范围，永远测不出信号。
2. **每轮必须研究 1 个低分候选**（现在是「中位分校准位」，应改为**最低分位**）：
   这是唯一能打破自证循环的办法。由 `qr claim` 强制，不是口头要求。
3. **七维分数落进 frontmatter**（`score_dims: 2,1,2,1,2,0,2`），`qr claim --dims` 校验格式
   （7 项、各 0-2、和 = 分子）。

### P1 · 换掉自评

4. **打分与提案分离**：让另一个 agent（不看提案来源）打分，或至少多评委取中位数。
   最低成本方案：同一轮内交叉打分。

### P2 · 换 label

5. **别用 PASS 做目标**（3% base rate，需要 n≈5000 才有功效，永远攒不到）。
   改用 **「是否在 A 层快速证伪阶段被淘汰」**——每轮必得、base rate 高、事件充足。
   打分卡真正该优化的是**淘汰率**（把坏主意提前筛掉），不是命中率。
6. **把 `screen_verdict`（成本闸实测）纳入 scorecard 回验**，它是现成的客观特征。

### P3 · 维度瘦身

7. **7 维砍到 4 维**：维度 1/2/6 高度相关，合并成一个「机理」维度。
   保留 4（成本余量）和 7（证伪速度）——它们是唯一独立的两个。
8. **证伪速度不该是 1/7 的权重，而应该是排序键**：快的先做，单位时间信息量最高。

### P4 · 评估方式

9. `qr scorecard` 补上：AUC + Hanley-McNeil CI、Fisher 精确检验、分档 lift、
   **并明确打印「当前样本量的功效」**，避免把「测不出来」误读成「测出无效」。
10. **权重保持等权**：n=99、15 个事件下拟合 7 个权重 = 2 事件/参数，远低于 10 EPV 的经验线。
    Dawes (1979) 的结论是等权（unit weights）在小样本下稳定优于回归拟合权重。

## 六、一句话

> 打分卡的问题不在七个维度选得对不对，而在它同时犯了三个错误：
> **自评**（有实测偏差）、**取值范围压缩**（有实测偏差）、
> **在 15 个事件上试图检出效应**（功效 < 0.12）。
> 任意一个单独出现都足以让 AUC=0.59 无法解释。
