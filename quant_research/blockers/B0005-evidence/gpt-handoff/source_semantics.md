# B0005：pctChg、除权参考价与经济总收益的独立核实

核实日期：2026-09-05。执行者：gpt / source_semantics。仅证据研究，未改回测、生产、共享台账或已有数据。

## 结论

**不能把 `cumprod(1 + pctChg / 100)` 无条件标为真实经济总收益。** 它首先是以交易所每日参考前收盘价为分母的涨跌幅连乘。该口径可以消除多数除权断点、用于行情连续性检查，但不自动满足投资者的分红到账、再投资成交、送配股、税费与资金守恒要求。ETF、股票和现金腿必须分别验收；验证股票的 Baostock 字段不能直接证明东方财富 ETF 后复权序列正确。

## 1. Baostock 官方字段定义

直接读取 [Baostock 官方 A 股 K 线文档](https://www.baostock.com/mainContent?file=stockKData.md)，已通过实际浏览器重新加载此 URL 并核实正文，非引用第三方镜像。新站为动态页面，普通网页提取可能只返回空壳。

- `pctChg` 是百分数：`100 * (close / preclose - 1)`。
- 公司行动日的 `preclose` 使用交易所计算公布的除权除息参考价，并非昨日真实成交收盘。
- 官网同时介绍“涨跌幅复权法”可维持资金使用率。这是在其复权模型内的描述，不能据此省略可成交再投资假设，或把任何源的 hfq 收盘比值等同于实际账户总回报。

## 2. 不依赖数据供应商的代数反例

设前日真实收盘 `P`、每股实际现金分红 `D`、除息日收盘 `C`，无送配股、无税费、无参考价四舍五入、无差异化分红。

```text
参考价 Q = P - D
报价涨跌幅 r_quote = C / (P - D) - 1
持股加现金的税前经济回报 r_wealth = (C + D) / P - 1
r_wealth = r_quote * (P - D) / P
```

例如 `P=10, D=1, C=9.9`：报价涨幅是 10%，股东财富从 10 变为 `9.9+1=10.9`，回报是 9%。即使没有数据缺陷，两者通常也不相等。

若假设分红在除息日前已可用，并恰能按 `Q` 即时买到零碎份额，涨跌幅连乘才可解释为这种理想化再投资路径；`Q` 是参考价，不能默认是可成交价格。若采用除息日收盘再投的研究型总收益，单日因子是 `(C+D)/P`；若分红晚到账，真实执行需另计应收红利和现金，可交易资金不能提前增加。

## 3. 真实反例：龙江交通 601188，2025-07-24

本地只读数据：`astock_quant/data_bs/daily/sh_601188.csv`。

| 日期 | close | pctChg (%) |
|---|---:|---:|
| 2025-07-23 | 3.6700 | -0.271700 |
| 2025-07-24 | 3.6200 | 0.555600 |

发行人 [2024 年度权益分派实施公告（上交所原始 PDF）](https://big5.sse.com.cn/site/cht/www.sse.com.cn/disclosure/listedinfo/announcement/c/new/2025-07-18/601188_20250718_IHRJ.pdf) 第 1–3 页明确：实际每股现金分红 **0.071 元**；因回购账户不参与分配，计算参考价采用的折算红利是 **0.070 元**；除息和现金发放均为 2025-07-24。

```text
参考前收盘 = 3.67 - 0.070 = 3.60
报价收益 = 3.62 / 3.60 - 1 = 0.55555556%
税前经济收益 = (3.62 + 0.071) / 3.67 - 1 = 0.57220708%
差值 = 1.66515289 bp
```

本地 pctChg 与报价收益吻合，却与税前经济回报不同。**`P - preclose` 也不能直接当投资者实际每股分红**：差异化分红与参考价舍入已经提供反例。若从舍入后的 pctChg 反推 preclose，还会再引入反推精度问题。

## 4. 511880 现金腿也必须验收

已快速核实 [银华交易型货币市场基金 A/B 类分红公告，2025-12-26（上交所原始 PDF）](https://www.sse.com.cn/disclosure/fund/announcement/c/new/2025-12-26/511880_20251226_IIQW.pdf)：511880 是 A 类，按年现金分配，不是 C 类的每日红利再投资。此次每份派 **1.1553 元**；场内除息日 **2025-12-31**，场内现金发放日 **2026-01-07**。因此 H0047 的 511880 hfq 现金腿不能因属于货币基金就豁免：应检查年度除息缺口、是否重复计入分红，以及跨到账日的再投资假设。本次未对 511880 原始行情做数值重算，不能声称已证明其当前 hfq 数据错误。

## 5. 可实施口径

1. **立即分清用途**：将 pctChg 连乘称为“参考价涨跌幅连乘 / quote-return proxy”，允许作为对照和发现除权异常的诊断；不得直接作为可交易总收益验收基准。供应商 hfq/QFQ 也须保留源与算法标识。
2. **事件数据独立建立**：保存原始 OHLC、实际昨日收盘、供应商 preclose、pctChg，以及实际每股现金分配、登记日、除息日、到账日、送转比例、配股支付和可交易日、公告 URL。真实分配额须来自事件表，不能只从除权缺口反推。
3. **研究型总收益与账户收益分开**：纯现金分红下的研究因子明确用 `(C+D)/P` 并写明再投资时点；实际策略则维护股数、可用现金、应收红利、配股现金流与费用。送配股需以账户股数变动核算，不能照搬纯现金公式。
4. **验收必须覆盖持仓腿**：对 H0047 的股票 ETF 和 511880，分别核对普通交易日、现金分红日、拆分/送配股日、到账日及交易稀疏日。先比较供应商变换与官方事件导致的财富变化，再决定是否替换数据；本证据不能单独解除 B0005 或恢复暂停策略。

## 复现本地反例

```python
import csv
from pathlib import Path
p = Path('astock_quant/data_bs/daily/sh_601188.csv')
rows = {r['date']: r for r in csv.DictReader(p.open())}
P = float(rows['2025-07-23']['close'])
C = float(rows['2025-07-24']['close'])
D_actual, D_reference = 0.071, 0.070
print(rows['2025-07-23'], rows['2025-07-24'])
print('quote_pct', 100 * (C / (P-D_reference) - 1))
print('gross_wealth_pct', 100 * ((C+D_actual) / P - 1))
```
