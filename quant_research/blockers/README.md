# 阻塞记录

一个 agent 发现「不该由我自己决定」的事情时，在这里开一条记录，然后停下当前这一轮。
**不要把阻塞写在 `rounds/*.md` 的散文里** —— 下一个 agent 读不到状态，只能重新推导一遍
「这条还算不算数」，那正是之前一整个会话被烧掉的原因。

```bash
./qr blocker open "验收门禁能被无效统计值绕过" --severity HALT \
     --evidence protocol_issues/2026-09-05-gpt-nonfinite-permutation/
./qr blocker list          # 未关闭的；有 HALT 时退出码 1
./qr blocker close B0001 "已按 v2 修复并登记版本，复现三例全部转 FAIL"
```

## 严重级

| 级别 | 挡不挡开工 | 用在什么时候 |
|---|---|---|
| `HALT` | 挡。所有 agent 的 `qr start` 退出码 1 | 协议算错了、门禁能被绕过、出现 PASS 候选需要人看 |
| `ASK` | 不挡，但每次开工都提示 | 需要花钱、需要注册账号、方向该由人定 |
| `WARN` | 不挡 | 知道有这个毛病，但够不着当前结论 |

选级别的判据只有一句：**它会不会让别人正在做的研究得出错误结论。** 会 → `HALT`；
只是让你自己这一轮做不下去 → `ASK`；两者都不是 → `WARN`。

单个 agent 卡住不该让整支编队停摆，所以 `ASK` 和 `WARN` 一律不挡开工。
