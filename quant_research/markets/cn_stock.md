# 市场年鉴 · cn_stock（A 股）

来源：`astock_quant/README.md` 与 `astock_quant/platform_strategy_audit_prompt.md` 的实测记录。

## 1. 可交易性
- 宇宙：代码空间穷举建池，含 255 只样本期内退市股（**不许改用"当前上市列表"，那是幸存者偏差**）。
  PIT 可投池规则：上市满 250 日 / 未停牌 / 成交额达标 / 剔除疑似 ST。
- **个股不能做空**——多空年化再漂亮也拿不到，只能看多头端。
- 交易时段：连续竞价 + 集合竞价；**T+1**，当日买入次日才能卖。
- 涨跌停：开盘涨停不可买、跌停不可卖、一字板双向不可成交；停牌不可交易并按上一有效价估值。

## 2. 成本（锁死）
- 佣金万 2.5 + 过户费十万分之一 + 滑点单边 10bp + 印花税卖出单边（2023-08-28 起减半）。
- 实际口径：**单边 12.6bp 买 / 22.6bp 卖，双边约 0.35%**。
- **年化换手 20 倍 = 每年白交 3.5%。周频以上调仓、毛 alpha 不到 4% 的策略可以直接判死。**

## 3. 数据
- `astock_quant/data/panel/*.parquet`：2836 个交易日 × 5282 只，2015-01 ~ 2026-09。
  字段 open/high/low/close（**后复权**）、volume（统一成「手」）、amount、close_raw。
- 读法：`from aq import panel; p = panel.load_panels()`
- **前复权是未来函数**（未来分红送转会改写历史价）。见到 `fq='pre'` / `adjust='qfq'` 立刻标红。
- 财务数据必须按**公告日**而非报告期对齐；拿不到 PIT 公告日就写"无法验证"，不要凑合。
- **PIT 财报面板现成**：`astock_quant/data/panel/{roe,bps,pb,ocf}.parquet`（2836×5282，公告日对齐，~每年更新一次）。
  质量因子可直接复用（H0022）；`build_pb_roe_factors.py` 是构建源头。

## 4. 基准
- 横截面选股：`universe.equal_weight_benchmark(p, mask)`（同池等权）。**跑不赢它=选股这步没加分。**
- 附报沪深300 / 中证500 作为"不选股就买指数"的对照。

## 5. 已知的坑

### ⚠️ 复权口径：腾讯的 hfq 是加法复权，不能拿来算收益（2026-09-05 坐实）

腾讯 fqkline 返回的 `hfq = k·raw + c` 是**加法复权**。加法项进了收益率的分母，于是
`r_hfq = r_raw × (k·raw/hfq)` —— 日收益被一个每天都在变、小于 1 的系数系统性压缩。
工商银行年化波动 hfq 报 0.1193，交易所口径是 0.1837，低估 35%。

**现在的正确取数**：`panel.load_panels()` 给出的 `open/high/low/close` 已经是重建的
**乘法复权**价（`scripts/rebuild_adjusted.py` 的产物，与 baostock 的交易所口径逐日
对齐到 1.6e-07）；`*_raw` 是不复权价。**判涨跌停、反推 ST 必须用 `*_raw`** ——
涨跌停价是拿前一日不复权收盘价乘 1±幅度、四舍五入到分算的，除权日的总收益天然不等于
价格涨跌幅，拿任何复权价去比阈值都一定错。`rules.tradability` 已经这么做了。

**不要再直接调 `ds.fetch_history(..., fq="hfq")` 算收益。** 详见 `blockers/B0005-*`。

### ⚠️ 可投池少了 307 只疑似配股的股票（选择偏差风险，未量化）

重建复权序列时，**配股无法自动定总收益**——股东要掏钱，「参没参与」是投资者的选择，
总收益取决于这个选择，工具不替它决定。所以这些标的被整只隔离，没有进面板：

| 隔离原因 | 只数 |
|---|---|
| 疑似配股（解出负现金流） | 307 |
| 事件前后样本不足，仿射解不出 | 89 |
| 仿射与交易所口径不自洽 | 23 |
| 没有 baostock 对照，无法定位事件也无法对账 | 36 |
| 合计影响 | 5477 只中 413 只未进面板，最终面板 4906 只 |

**这是一个真实的选择偏差风险，而且没有被量化。** 配股集中发生在需要融资的公司身上，
整批剔掉可能让剩下的池子系统性更健康。实测它已经让两张卡的结论出现相反方向的移动：
H0002 变差、H0040 从 STOP 变 GO（见 `blockers/B0011-*`、`blockers/B0012-*`），
而**这两处变化里有多少来自口径修正、多少来自池子变化，尚未拆开**。

拆开的方法是显然的：为那 307 只按「不参与配股」的口径生成近似序列（相当于持股比例被
稀释，是可计算的），让它们回到池子里，再跑一遍对比。**这本身是一个值得单独立卡的题目**
——它影响的不是某一张卡，而是以后所有 A 股研究的池子定义。谁先做谁 `qr claim`。

在它被解决之前：**任何 cn_stock 的结论都应当在卡片里写明「池子排除了 413 只标的」**，
不要默认可投池等于全市场。

1. **科创板成交量单位是「股」不是「手」**，比其他板块大 100 倍（`panel.build_panel` 已折算）。
2. **脏数据**：连续交易日 |涨跌幅| > 25% 的记录几乎都是复权因子出错或退市整理期，一根就能打穿等权净值（已自动截断）。
3. **调仓日权重要先补 0 再 ffill**，直接 ffill 会让上期选中本期落选的股票把旧权重带下去，权重和能滚到 6 倍。
4. **最小成交额阈值**：引擎跳过小于总资产 0.05% 的委托，持仓上千只时会**静默跳过**，回测悄悄变成"拿着不动"。
   跑完必查 `res.blocked_frac`，**超过 5% 结论作废**；这是相对阈值，加资金没用。
5. **Rank IC 高 ≠ 能赚钱**：有因子 ICIR 1.02、t=7.92，等权组合净超额是 0。IC 只用于初筛。
6. **A 股中期动量是负的**（见 H0001），别照搬美股动量。
7. **因子信息几乎全在空头端**（见 H0002）：价值在"避开最差的 20~40%"，不在"精选前 20%"。
8. **A股质量因子（ROE+稳定性+OCF/BPS）2016-2021 真实可交易、2022-2026 已衰减为负**（见 H0022）：
   IS 两段 t≈2.3-2.6、置换分位 100%，但 TEST alpha −1.18%(t=−0.54)、DSR 0.53、IC≈0——复现券商"ROE 因子 2021 起失效"。
   别从零再做一次；重启线 = TEST 滚动质量 alpha 转正且 t≥2。
9. **宽持仓 book 的可成交性**：月频 top20%（约 800 只）在默认 min_trade_frac=5e-4 下 blocked_frac 达 8.97%>5% 作废；
   需 `min_trade_frac=5e-5`（0.5bp of equity）才能降至 0.29%。这是相对阈值，加资金没用（H0022 实测）。
10. **qr 脚本 bash 3.2 bug 已修**：`$var` 后紧跟 CJK 字符（如 `$v，`）会触发 unbound variable（`qr search`/`qr verdict` 曾因此报错）；
   已改为 `${var}` 大括号写法（2026-09-04）。
11. **A股小市值溢价（流通市值最小 20% 纯多）真实存在但不可单独上仓位**（H0024，PARK）：
   2016-2026 净年化 5.05%、对同池等权年化超额 +5.43%（TEST 2022-26 +7.92%）、随机选 100% 跑不过它、去掉任一年仍成立（最低 t=2.29）；
   但夏普仅 0.19、DSR 0.83<0.90、年度收益在 +29%~−30% 间抽风、FULL IC≈0 而 TEST IC 0.037(t=7.06) 说明**信号强度随 regime 剧烈切换**。
   它是组合里的**小盘风格暴露（β_SMB 1.2-1.3），不是独立 alpha 源**——2017「漂亮50」与 2024-01 小微盘踩踏两次演示崩盘形态。
   数据可用：`panel_bs/float_mktcap`（PIT 当日可知，退市股覆盖 97.7%，幸存者偏差检查通过）；重启线=DSR≥0.90 且 TEST t≥2，或并入小盘多因子组合。
12. **A 股的「隔夜」和「日内」是两个方向相反的市场，别把美股直觉搬过来**（H0028 实测，2016-2026，
   可投池每日中位 2422 只，等权口径）：**隔夜段年化 −21.7%、日内段年化 +28.6%、全天 +0.04%**。
   美股是反过来的（隔夜赚走几乎全部、日内约等于零，LPS 2019 JFE）。这是 T+1 的指纹：
   当日买入次日才能卖 → 没人愿意为隔夜风险付钱。**任何"隔夜动量/隔夜折价"的直觉先看这一行。**
   数据本身是干净的：`(1+隔夜)(1+日内) − (1+全天)` 最大绝对误差 2.4e-7 → open 与 close 共用同一套后复权因子。
13. **「过去 20 日累计隔夜收益最低的一档」是全池最该躲开的一档，不是最该买的**（H0028，FAIL）：
   五分层未来 20 日平均总收益 Q1 −0.08% / Q2 +0.54% / Q3 +0.71% / Q4 +0.78% / Q5 +0.44%，
   **形状是驼峰不是单调**——信息集中在"Q1 特别差"（比中位档低 0.77~0.84 个百分点/20 日，
   TRAIN/VALID/TEST 三段分别 −0.844/−0.774/−0.765，稳到不像话），Q5 反而掉回来。
   买 Q1 的纯多组合对同池等权年化 −7.7%（**毛口径就已经 −5.0%，成本只占 1/3，不是成本问题**）。
   与坑 #7「因子信息几乎全在空头端」同构。**顺带量到一个可复用的画像**：Q1 持仓未来一年内停止交易的比例
   0.65%，是全池基线 0.29% 的 **2.26 倍**——持续隔夜跳空下跌确实带退市/困境信息，但量级远不足以解释 −9%/年。

14. **"分层完美单调 + 逐年全为正 + 幅度很大"三个特征同时出现时，先去查时间戳，不要先写卡**（H0037 自己踩的）：
    用「公告窗口收益 → 后续 40 日漂移」做对照时，信号取了**成交当天的收盘价**、成交却在同一天开盘，只差一天，
    结果是五分层完美单调（Q1 +1.01% → Q5 +5.90%）、前 20% 超额 **+15.6%/年**、2015-2026 **12 年全部为正**。
    把成交推到"信号收盘可知的次日开盘"之后，同一份数据只剩 **+1.06%/年**（中位数口径 −1.48%，
    剔除一字涨停买不到的名字后 −0.48%），五分层完全平坦。**那 15.6% 是 100% 的时间错位。**
    A 股事件研究里 `dates.searchsorted(公告日, "right")` 得到的是"公告日之后第一个交易日"，
    它的**收盘**不可用于当天开盘的决策——这个 off-by-one 在事件驱动卡里极易发生。
15. **A 股业绩预告的"同比变动幅度"不是盈余意外，没有选股价值**（H0037，FAIL）：
    67,936 个事件（2015-2026，akshare `stock_yjyg_em` 46 个报告期零失败）上，
    按变动幅度队列内排名的前 20% 未来 40 日 +3.57%，**同队列等权是 +3.99%**，毛超额 −2.57%/年；
    五分层 3.38/4.46/4.67/3.93/3.53% 是**驼峰**（与坑 #7、H0028 的 Q1 同构）。
    附带量到两件事：① 前 20% 次日一字涨停买不到只有 **0.60%**（全池 8.37%），
    说明"涨得多"和"超预期"在数据上就是分开的；② 预告类型的档间价差是**反着**排的——
    续盈 +13.0%/年、略增 +10.3% 好于预增 −6.2%、预减 −5.5%，
    疑似质量/低波换马甲，追之前必须先正交化。要真做 A 股 PEAD，先解决**分析师一致预期**，本机不可得。

16. **`astock_quant/data_bs/index_members.csv` 是一份被低估的 PIT 资产**（H0040 发现）：
    **115 个月度快照**，hs300（每期 300 只）+ zz500（每期 500 只），**2015-01-01 ~ 2024-07-01**，
    带 `updateDate`（该名单实际更新日 = PIT 时间戳），代码格式是 `sh.600000`（去掉点号即可对上面板）。

    局限：**月度分辨率、拿不到调样公告日**，做公告窗口必须另找中证指数公司的公告源。
17. **A 股指数调样的强制流是真的，但钱在空头端，而 A 股不许做空**（H0040，FAIL 成本吃穿）：
    2,091 个事件（2015-2024）沿"强制买入→强制卖出"这条轴**单调排列**，未来 40 交易日对同池等权的年化超额：
    **调入沪深300 −13.11%｜调入中证500 −6.16%｜纯移出中证500 +2.54%｜从沪深300 掉到中证500 +11.36%**。
    **同市值分档对照几乎不改变任何一行**（例如调入 300 是 −13.18%），
    所以这不是 H0024 小市值溢价的换皮。能做多的那一端毛超额只有 2.5%/年，
    而 40 日重叠持有的成本就是 2.15%/年 → 毛/成本 1.18，压力档 0.59。
    这是坑 #7「因子信息几乎全在空头端」的**第四次**出现，而且这次是制度锁死的。
18. **强制流研究里，"净压力大小"和"能不能买到"是方向相反的两个筛子**（H0040）：
    看起来最干净的"纯移出中证500"事件，**49.2% 过不了 PIT 可投池闸**（停牌/成交额不足/疑似 ST），
    再加 4.1% 一字涨停买不到；而压力没那么"纯"的"沪深300 掉到中证500"反而流动性好得多
    （市值分位中位 0.889 vs 0.740）且超额是它的四倍。**别只按机理纯度挑事件定义。**

19. **事件研究的最小体检是四件套：均值差 / 配对 t / 胜率 / 中位数差**（H0040→H0041 自己踩的）：
    "沪深300 降级到中证500 后反弹"这条线索，只看组间均值差是 +11.4%/年、看起来有余量；
    补上另外三件后同一段样本只剩 **t=1.62、胜率 50.3%、中位数 +0.48%/年**，
    2024-08~2026-09 的全新样本上 **t=0.05、胜率 37.5%、中位数 −29.8%/年**。
    **均值为正 + 中位数≈0 + 胜率抛硬币 = 少数几只大赢家，不是一个效应**——
    这是本台账第四次撞上同一形状（H0007 / H0033 / H0039 / H0041）。
20. **`baostock` 能补出到 2026-08 为止的 PIT 成分名单**（`query_hs300_stocks` / `query_zz500_stocks(date=...)`，
    返回带真实 `updateDate`），与坑 #16 的 `index_members.csv`（止于 2024-07）拼接后

21. **跨境 ETF（QDII）的三条数据事实与一个免费的 PIT 制度标记**（H0072 实测 2026-09-06）：
    - **行情走腾讯、净值走 akshare**：`fund_etf_hist_em`（东财行情）仍是 `RemoteDisconnected` 不可用
      （与 `markets/cn_index_futures.md` §3 记录一致）；**`fund_etf_fund_info_em`（净值）可用**，
      返回 `单位净值` / `累计净值` / **`申购状态`**。
    - **`申购状态`（"场内买入" / "暂停申购"）是一个免费、逐日、当时可见的制度约束标记**——
      它直接告诉你申赎套利通道通不通。任何跟"套利通道是否被行政关闭"有关的课题都能拿它做机理判别线，
      不必猜。实测暂停申购占比：513100 **39.8%** / 159612 **44.4%** / 513500 14.8% /
      159632 11.1% / 513300 10.6% / 159941 **仅 3.5%**——同一个指数、同一段时间，额度松紧完全不同。
    - **份额折算（拆分）的净值日与价格日差一天**（513100 净值 2022-01-13、价格 2022-01-14；
      159941 1:4 @2022-07；513500 1:2 @2022-03）。**任何"价格 ÷ 净值"的口径必须先各自去折算
      并对折算日前后设黑名单**，否则会凭空出现一天 5 倍的假溢价。
22. **载体比较类课题的干净口径：同族两只相除**（H0072）。跟踪同一指数的两只 ETF，
    `P_i,t+1/P_i,t ÷ P_j,t+1/P_j,t` 就是干净的相对收益——**自动抵消指数收益、份额折算和分红**，
    因此**不需要复权价**（腾讯的加法复权本来也不能直接算收益，见项目 CLAUDE.md）。
23. **"收盘出信号、次日开盘成交"的 P&L 必须用开盘→开盘算**（H0072 自己踩的，代价 1.3~2.2pp/年）：
    用"收盘→收盘 + shift(1)"看起来也没用未来数据，但它把**隔夜跳空那一段白送给了新持仓**。
    在跨境 ETF 上这一段恰好装着全部的边际——错版能把某一族的 NW t 从 0.07 抬到 2.06、直接越过判读线。
