# 市场年鉴 · cn_stock（A 股）

来源：`astock_quant/README.md` 与 `astock_quant/platform_strategy_audit_prompt.md` 的实测记录。

## 1. 可交易性
- 宇宙：代码空间穷举建池，含 255 只样本期内退市股（**不许改用"当前上市列表"，那是幸存者偏差**）。
  PIT 可投池规则：上市满 250 日 / 未停牌 / 成交额达标 / 剔除疑似 ST。
- **个股不能做空**——多空年化再漂亮也拿不到，只能看多头端。
- 交易时段：连续竞价 + 集合竞价；**T+1**，当日买入次日才能卖。
- 涨跌停：开盘涨停不可买、跌停不可卖、一字板双向不可成交；停牌不可交易并按上一有效价估值。

## 2. 成本（锁死）
- 佣金万 2.5 + 过户费十万分之一 + 滑点单边 10bp + 印花税卖出单边（2023-08-28 起减半）。
- 实际口径：**单边 12.6bp 买 / 22.6bp 卖，双边约 0.35%**。
- **年化换手 20 倍 = 每年白交 3.5%。周频以上调仓、毛 alpha 不到 4% 的策略可以直接判死。**

## 3. 数据
- `astock_quant/data/panel/*.parquet`：2836 个交易日 × 5282 只，2015-01 ~ 2026-09。
  字段 open/high/low/close（**后复权**）、volume（统一成「手」）、amount、close_raw。
- 读法：`from aq import panel; p = panel.load_panels()`
- **前复权是未来函数**（未来分红送转会改写历史价）。见到 `fq='pre'` / `adjust='qfq'` 立刻标红。
- 财务数据必须按**公告日**而非报告期对齐；拿不到 PIT 公告日就写"无法验证"，不要凑合。
- **PIT 财报面板现成**：`astock_quant/data/panel/{roe,bps,pb,ocf}.parquet`（2836×5282，公告日对齐，~每年更新一次）。
  质量因子可直接复用（H0022）；`build_pb_roe_factors.py` 是构建源头。

## 4. 基准
- 横截面选股：`universe.equal_weight_benchmark(p, mask)`（同池等权）。**跑不赢它=选股这步没加分。**
- 附报沪深300 / 中证500 作为"不选股就买指数"的对照。

## 5. 已知的坑
1. **科创板成交量单位是「股」不是「手」**，比其他板块大 100 倍（`panel.build_panel` 已折算）。
2. **脏数据**：连续交易日 |涨跌幅| > 25% 的记录几乎都是复权因子出错或退市整理期，一根就能打穿等权净值（已自动截断）。
3. **调仓日权重要先补 0 再 ffill**，直接 ffill 会让上期选中本期落选的股票把旧权重带下去，权重和能滚到 6 倍。
4. **最小成交额阈值**：引擎跳过小于总资产 0.05% 的委托，持仓上千只时会**静默跳过**，回测悄悄变成"拿着不动"。
   跑完必查 `res.blocked_frac`，**超过 5% 结论作废**；这是相对阈值，加资金没用。
5. **Rank IC 高 ≠ 能赚钱**：有因子 ICIR 1.02、t=7.92，等权组合净超额是 0。IC 只用于初筛。
6. **A 股中期动量是负的**（见 H0001），别照搬美股动量。
7. **因子信息几乎全在空头端**（见 H0002）：价值在"避开最差的 20~40%"，不在"精选前 20%"。
8. **A股质量因子（ROE+稳定性+OCF/BPS）2016-2021 真实可交易、2022-2026 已衰减为负**（见 H0022）：
   IS 两段 t≈2.3-2.6、置换分位 100%，但 TEST alpha −1.18%(t=−0.54)、DSR 0.53、IC≈0——复现券商"ROE 因子 2021 起失效"。
   别从零再做一次；重启线 = TEST 滚动质量 alpha 转正且 t≥2。
9. **宽持仓 book 的可成交性**：月频 top20%（约 800 只）在默认 min_trade_frac=5e-4 下 blocked_frac 达 8.97%>5% 作废；
   需 `min_trade_frac=5e-5`（0.5bp of equity）才能降至 0.29%。这是相对阈值，加资金没用（H0022 实测）。
10. **qr 脚本 bash 3.2 bug 已修**：`$var` 后紧跟 CJK 字符（如 `$v，`）会触发 unbound variable（`qr search`/`qr verdict` 曾因此报错）；
   已改为 `${var}` 大括号写法（2026-09-04）。
11. **A股小市值溢价（流通市值最小 20% 纯多）真实存在但不可单独上仓位**（H0024，PARK）：
   2016-2026 净年化 5.05%、对同池等权年化超额 +5.43%（TEST 2022-26 +7.92%）、随机选 100% 跑不过它、去掉任一年仍成立（最低 t=2.29）；
   但夏普仅 0.19、DSR 0.83<0.90、年度收益在 +29%~−30% 间抽风、FULL IC≈0 而 TEST IC 0.037(t=7.06) 说明**信号强度随 regime 剧烈切换**。
   它是组合里的**小盘风格暴露（β_SMB 1.2-1.3），不是独立 alpha 源**——2017「漂亮50」与 2024-01 小微盘踩踏两次演示崩盘形态。
   数据可用：`panel_bs/float_mktcap`（PIT 当日可知，退市股覆盖 97.7%，幸存者偏差检查通过）；重启线=DSR≥0.90 且 TEST t≥2，或并入小盘多因子组合。
12. **A 股的「隔夜」和「日内」是两个方向相反的市场，别把美股直觉搬过来**（H0028 实测，2016-2026，
   可投池每日中位 2422 只，等权口径）：**隔夜段年化 −21.7%、日内段年化 +28.6%、全天 +0.04%**。
   美股是反过来的（隔夜赚走几乎全部、日内约等于零，LPS 2019 JFE）。这是 T+1 的指纹：
   当日买入次日才能卖 → 没人愿意为隔夜风险付钱。**任何"隔夜动量/隔夜折价"的直觉先看这一行。**
   数据本身是干净的：`(1+隔夜)(1+日内) − (1+全天)` 最大绝对误差 2.4e-7 → open 与 close 共用同一套后复权因子。
13. **「过去 20 日累计隔夜收益最低的一档」是全池最该躲开的一档，不是最该买的**（H0028，FAIL）：
   五分层未来 20 日平均总收益 Q1 −0.08% / Q2 +0.54% / Q3 +0.71% / Q4 +0.78% / Q5 +0.44%，
   **形状是驼峰不是单调**——信息集中在"Q1 特别差"（比中位档低 0.77~0.84 个百分点/20 日，
   TRAIN/VALID/TEST 三段分别 −0.844/−0.774/−0.765，稳到不像话），Q5 反而掉回来。
   买 Q1 的纯多组合对同池等权年化 −7.7%（**毛口径就已经 −5.0%，成本只占 1/3，不是成本问题**）。
   与坑 #7「因子信息几乎全在空头端」同构。**顺带量到一个可复用的画像**：Q1 持仓未来一年内停止交易的比例
   0.65%，是全池基线 0.29% 的 **2.26 倍**——持续隔夜跳空下跌确实带退市/困境信息，但量级远不足以解释 −9%/年。
