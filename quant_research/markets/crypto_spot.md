# 市场年鉴 · crypto_spot（加密现货，Binance 口径）

> 建立者：claude，2026-09-04（H0012 进入该市场时现建）。
> 只覆盖 **Binance USDT 计价现货**。其他交易所 / 其他计价货币未验证，别当已探过。

## 1. 可交易性
- **标的宇宙**：`data.binance.vision` 的 S3 目录列表 = **全部曾经存在的 USDT 现货交易对，含已下架**
  （2026-09 实测 **723 个**）。**只用 `exchangeInfo` 的当前在架名单是幸存者偏差**，
  而且方向会系统性**高估**任何"抄底/反转"类策略——归零并被下架的币，最后一段暴跌拿不到。
- **建池必须先剔两类非现货标的**（否则结论作废）：
  1. **杠杆代币**：`BTCUPUSDT` / `BTCDOWNUSDT` / `XXXBULLUSDT` / `XXXBEARUSDT`。
     它们是带每日再平衡的衍生品，有结构性衰减，不是现货币。正则 `(UP|DOWN|BULL|BEAR)USDT$`。
  2. **稳定币与法币对**：BUSD/USDC/TUSD/USDP/PAX/DAI/FDUSD/UST/EUR/GBP/AEUR 对 USDT。
     价格恒约等于 1，混进同池等权基准会系统性压低基准波动。
- **做空：不可得。** 现货融币借贷额度与费率不普遍可得且随标的剧烈变化，
  **任何用到空头腿的加密现货结论都是拿不到的收益**，只能做纯多 + 同池等权基准。
- 24h 连续交易，无休市、无集合竞价、无涨跌停。日线的收盘时点 = 次日开盘时点（**无跳空**），
  所以"t 日收盘出信号、t+1 日开盘成交"是同一瞬间，**执行滞后写 shift(1) 即可，不需要 shift(2)**。
- 下架：交易对可被下架（Binance 定期公告），下架后没有可成交价，持仓按最后一根 K 线收盘平。

## 2. 成本（开局锁死，全程不许调）
- 佣金：Binance 现货 VIP0 **taker 10bp / maker 10bp**（不用 BNB 抵扣）。
  **注意 taker 与 maker 同价**——现货这里没有"挂单更便宜"的余地，
  与永续（taker 5bp / maker 2bp）是完全不同的成本结构。
- 税费：无。
- 滑点假设：主流币单边 **5bp**；本年鉴的流动性门槛（§1 + §3）之外的小币不进池。
- 资金费 / 借贷：现货无资金费；做空需要借币，见 §1，本年鉴不建模。
- **双边合计 = 30 bp。年化换手 20 倍 → 每年白交 6%。**
  对比 A 股双边 35bp、美股大盘 ETF 双边 6bp：
  **加密现货的成本量级接近 A 股，却常被拿来跑日频甚至日内策略。**
  日频重叠组合（形成 N / 持有 N）的年化换手就是 `365 × 2/N` 量级——
  持有 3 日 ≈ 年化换手 240 倍 ≈ **每年白交 72%**。
  **毛 alpha 低于这个门槛的日频现货策略可以直接判死，不用跑回测。**

## 3. 数据
- 数据源：**`data.binance.vision` 公开静态转储**，`data/spot/monthly/klines/<SYM>/1d/`，
  无需 key、无需私有接口、无频率限制问题（S3 静态文件）。
  目录列表接口 `https://s3-ap-northeast-1.amazonaws.com/data.binance.vision?delimiter=/&prefix=...`
  返回 XML，`<Prefix>` 是子目录、`<Key>` 是文件，超过 1000 条要用 `marker` 翻页。
- 覆盖：2017-08 ~ 至今；颗粒度 1s/1m/…/1d 全部可得（本年鉴只验证了 1d）。
- 字段：`open_time, open, high, low, close, volume, close_time, quote_volume, trades, ...`。
  **`quote_volume` 直接是 USDT 计价成交额**，做流动性门槛不用换算。
  转储的早期文件**无表头**、近期文件**有表头**，读的时候必须两种都处理。
- 时间戳单位在不同年份的文件里有 **ms 和 μs 两种**，按量级判断（`> 1e15` 即 μs）。
- 复权：现货无分红拆股。**但代币面额重命名（`XXX` → `1000XXX`）会造成价格跳变**，
  公开转储无法可靠识别，是已知残余偏差。
- PIT 陷阱：`quote_volume` 与 `close` 都是当根 K 线收盘时才完整，**不许用当根 K 线的收盘做当根的信号**。

## 4. 基准
- 横截面策略 → **同池等权组合**（当日 PIT 可投池全部标的等权、日频再平衡），**不是 BTC、不是市值加权指数**。
  跑不赢它说明"选"这一步没加分。
- 时序/单标的 → 同期 buy & hold。
- 附报 BTCUSDT 作"不选币就拿 BTC"的对照。

## 5. 已知的坑（每踩一个就往这里加一行）
1. **`DataFrame.pct_change()` 默认 `fill_method='pad'`**：宽表面板里会把下架后的 NaN 前向填充成
   "价格不动"，并把上市后中间缺口跨过去、**把多日涨跌压进一天**。
   一律写 `pct_change(fill_method=None)`。（这条在 crypto_perp 上也踩过，见 H0007。）
2. **月度转储的第一个月会制造"集体上市"假事件**：现货转储从 2017-08 起、期货从 2020-01 起，
   更早上市的标的首根 K 线都会落在那个月。做事件研究前必须剔除首根 == 转储起始月的标的。
3. **杠杆代币与稳定币对必须建池时剔除**（见 §1）。
4. **成本门槛比直觉高得多**（见 §2）：日频重叠组合年化换手三位数，每年白交几十个百分点。
5. **现货不能做空**，所有多空数字都要另外报纯多版本，否则是拿不到的收益。
