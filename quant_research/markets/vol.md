# 市场年鉴 · vol（CBOE VIX 期货 / 波动率衍生品）

> 建立：2026-09-04，trae（H0021 首次进入该市场）。数字为当时锁死值，后人不许静默改。

## 1. 可交易性
- 标的宇宙：CBOE Futures Exchange (CFE) 的 VIX 期货（代码 VX），月度循环、现金结算（结算到 SOQ=到期日 SPX 期权开盘价推算的 VIX 特别开盘价）；散户替代载体：VXX/UVXY/VIXY（多头）、SVXY（-0.5x 空头）
- 能否做空：期货天然可双向，保证金制（SPAN 初始保证金约为合约价值的 50-100%，危机时交易所上调）；VXX 借券做空常年借券费 1-12%/年（不可靠，回测禁用为口径）
- 交易时段：CFE Globex 近 23 小时（美东），日结算价 16:15 ET；VIX 期货到期日 = 到期次月第三周五往前数 30 天的那个周三（遇假日提前一日）
- 涨跌停：无 A 股式涨跌停；2018-02-05 后 CFE 引入过临时性稳定措施（定性的制度变化，量化影响未知）
- T+0、无锁定期；合约乘数 $1000 × VIX 点，最小变动 0.05 点（1 tick ≈ 名义的 25bp @VIX=20）

## 2. 成本（开局锁死，全程不许调）
- 期货佣金：~1.3bp/边（每张 $1.5-2.5，@VIX=20 名义 $20k）
- 滑点：M1/M2 常态价差 1-2 tick → 按保守 **10bp/边**（含佣金税费）锁死
- 无借券费（期货保证金制）；抵押品现金按 T-bill 计息（DTB3）
- **换手**：30 天恒定到期组合每日小步 roll，名义年交易量 ≈ 24×（卖旧买新双腿 ×12 轮/年）→ **年成本 ≈ 2.4%/年**。毛 carry 低于此值的变体直接判死。
- ETP 口径（仅作对照，不作回测口径）：VXX 费率 0.89%/年 + 点差 5-10bp + 借券费（空头不可靠）

## 3. 数据
- 数据源与获取方式：
  - CFE 官网 cfe.cboe.com 历史结算价 CSV（**本环境网络被墙，不可用**）
  - GitHub Morwane/vix-vol-carry（MIT）LSEG 拼接 VXc1/VXc2/VXc3 日线 2010-01~2026-06（TRDPRC_1=最后成交价，非官方结算价）
  - VIX 现货指数：CBOE CDN 官方 CSV（https://cdn.cboe.com/api/global/us_indices/daily_prices/VIX_History.csv，1990+，已验证）
  - VXX/VIXY/SVXY/^VIX3M/^GSPC：yfinance
  - DTB3：FRED fredgraph.csv（免 key）
- 覆盖区间 / 颗粒度 / 字段：日频收盘/结算价；2004-2009 的期货数据无免费源（Quandl CHRIS 需 API key）——**2010 前样本缺失，写在结论里**
- 复权：期货无复权概念；VXX 多次反向合股（4:1×2、8:1），**必须 auto_adjust 后再算收益**
- PIT 陷阱：期货结算价不会回改；LSEG TRDPRC_1 vs 官方结算价有微小差异（用 VXX 日收益交叉验证）；VIX3M 当日值当日收盘后才确定，做信号必须 T-1
- 已知脏数据模式：拼接合约 pct_change 有换月跳空（contango 时 +1~2 vol 点）——**必须 roll-aware**，roll 日持有合约真实收益 = 当日c1/前日c2 − 1

## 4. 基准
- 时序/单标的：**T-bill（DTB3）**——策略=现金+空头期货 overlay，无风险替代即现金；附报 SPX buy&hold（负 beta 语境）与做多同组合对照组

## 5. 已知的坑（每踩一个就往这里加一行）
1. **拼接合约的换月跳空不是收益**：直接 pct_change 会凭空多出 contango 缺口，roll 日收益要用持仓合约口径（c1(T)/c2(T−1)−1）。
2. **2018-02-05（Volmageddon）**：VX 前月盘中 +115%+，1x 空头单日可亏超名义本金；XIV 当日 -96% 清盘。回测必须允许"单日亏超 NAV→清盘重启"，不许 cap 收益率掩盖。
3. VXX 是 ETN（发行行 CS→UBS 2023），信用结构与期货直连不同；费率 0.89% 要加回才能还原纯指数。
4. SPVXSP 方法论：M1 权重 = (d2−30)/(d2−d1)（日历日），到期日自算（次月第三周五前 30 天的周三）；roll 日结算合约（SOQ 定价）的最后收益在拼接序列里观测不到，权重 ≤~15%×1天/月，用新 M1 当日收益近似，误差可忽略但要知道。
5. 远月（M4+）价差大流动性差，本市场回测只许碰 M1/M2/M3。
6. LSEG TRDPRC_1 是最后成交价：与官方结算价差异在尖峰日可能放大，用 VXX 相关性(>0.995)做门槛验证。
7. **Yahoo API 的 VXX 2009-2018 历史已丢**（2026-09 实测只剩 2018-01-25 起）；要 2011+ 的 SPVXSTR 口径用 VIXY（费率 0.85%，与 VXX 2018+ 交叉验证漂移 0.12%/年、与 SVXY−0.5x corr 0.997）。
8. **LSEG 拼接序列的换月日与官方到期日错位 −2~+3 天**（H0021 实测 204 个到期），用它复制 SPVXSP 会有 ±几%/年的 roll 噪音，只能做定性验证。
9. **日结算序列看不见隔夜路径**：2018-02-06 结算口径篮子 +3.2%，但同构真实产品 SVXY(1x) 当日 −83%（盘后 VX 盘中 +140%）——做空侧的日频回测系统性低估尾部，必须配盘中振幅诊断（VIX HIGH≥1.4×昨收 2011-2026 有 36 天）。
10. **SPVXSP 复制的换手模型**：roll 日 w1 从 ~0 跳回 1.0 是同一合约改身份（M2→M1）不是交易；真实换手 ≈ 2×12 轮 = 24×/年，误算会翻倍（H0021 踩过：43×→21.7×）。
11. **无杠杆 vol-target（cap=1）在 VIX 篮子上平均乘数只有 ~0.19**（篮子年化波动 ~65%），收益被砍到毛额 1/5；且减仓时机与 spike 后均值回归负对齐——随机时移置换分位 3.5%，择时是负贡献（H0021 V2）。
